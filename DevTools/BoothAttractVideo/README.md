# 부스 대기 영상 단축키 (할 일 289)

부스 PC에서 **Alt+\\** 를 누르면 지정한 영상이 모든 창(게임 포함) 위에 전체 화면으로 나오고,
**마우스나 키보드를 건드리면 꺼진다.** 게임과 따로 돈다.

- 영상 재생·입력 시 꺼짐 = **팟플레이어 화면 보호기**(`PotScreenSaver64.scr`)가 한다.
- 이 폴더의 스크립트는 **단축키만** 받는다. 윈도우 바로가기 단축키는 전체 화면 게임이 앞에 있으면 전달되지 않아서
  `RegisterHotKey` 로 직접 받는다. 설치 없음(윈도우 기본 PowerShell 5.1).
- 단축키: Alt+\\ (키보드에 따라 다른 키 코드 2개 모두 등록) + 예비 Ctrl+Alt+V.
- 단축키를 다 뗀 뒤 0.4초 있다가 띄운다 — 떼는 입력에 화면 보호기가 바로 꺼지지 않게.

## 부스 PC 설정
1. 팟플레이어 설치.
2. 이 폴더를 부스 PC 아무 곳에 복사.
3. 영상 지정 — 팟플레이어 화면 보호기는 윈도우 화면 보호기 목록에 안 나온다. 설정 창을 직접 띄운다:
   ```
   "C:\Program Files\DAUM\PotPlayer\PotScreenSaver64.scr" /c
   ```
   트레일러 파일(또는 폴더)과 반복 재생을 고르고 확인.
4. 자동 시작 — `Win+R` → `shell:startup` 폴더에 `Start-BoothVideoHotkey.bat` 바로가기를 넣는다.
   지금 바로 켜려면 `Start-BoothVideoHotkey.bat` 더블클릭(창 없이 상주).
5. 게임 설정창 **'백그라운드에서 소리 끄기'**(기본 켬)가 켜져 있는지 확인 — 영상이 앞에 오면 게임이 포커스를 잃어 게임 소리가 꺼진다(빌드만, 에디터 제외).

## 문제 해결
- 같은 폴더 `BoothVideoHotkey.log` — 단축키 등록 성공/실패, 누를 때마다 `단축키 id=…`·`재생` 이 남는다.
  - `등록 실패` = 다른 프로그램이 같은 단축키를 쓰는 중.
  - 눌러도 줄이 안 생김 = 스크립트가 안 떠 있음(작업 관리자에서 `powershell` 확인) 또는 다른 키.
- 팟플레이어가 다른 경로에 깔렸으면 `.bat` 의 실행 줄 끝에 `-Scr "경로\PotScreenSaver64.scr"` 를 붙인다.
- 끄기: 작업 관리자에서 명령줄에 `BoothVideoHotkey` 가 있는 `powershell` 을 종료.
- 한계: 화면 보호기를 띄우는 건 팟플레이어라 영상·종료 동작은 팟플레이어 설정을 따른다. 주 모니터 기준.
