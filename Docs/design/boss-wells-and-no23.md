# 보스 — 웰즈 & 23호 (Wells & No.23)

> 출처: 팀 기획안 정리. 7월 스코프의 **유일한 적**. 구체 수치는 러프(밸런스는 후순위).

## 컨셉
- **23호**: 우둔함 · 지능 낮음 · 괴력형. **거대 로봇 본체**(근접 공격 담당).
- **웰즈**: 고지능. **23호 위에 탑승한 여자아이**(폭탄 살포 담당).
- **관계성**: 웰즈는 괴물 로봇(23호 등)을 통해 가족애·우월감을 충족하려 하지만,
  로봇들을 소모품처럼 취급하며 희열을 느낀다.

## 보스 공격 & 기믹
- **특수 기믹은 "송전기" 단 하나.** 잡기/폭탄은 기믹이 아니라 **평상시 공격 패턴**이다.
- **23호(본체)** 가 근접 + 원거리 접근(점프/돌진) 공격을, 폭탄 살포는 위에 탄 **웰즈**가 담당.
- 23호의 공격은 **타겟 거리로 상태 선택**: 가까우면 근접(훅/어퍼컷/잡기), 멀면 원거리(JumpAttack/DashAttack).

### 근접 공격 (타겟이 가까울 때)
- **HookAttack**: **좌측 훅 / 우측 훅** — 콤보가 아니라 **각각 독립된 단타**.
- **UpperAttack**: 어퍼컷 — 적중 시 **공중에 뜸(Airborne)** 부여.
- **Grab(잡기, 쿨타임)**: 근접한 플레이어가 있을 때 **쿨타임마다 1회** 사용. 흐름 **잡기 → 전기 → 던지기**(CC 체인).
- (근접은 HookAttack / UpperAttack + Grab 까지가 전부.)

### 원거리 공격 — 접근 (타겟이 멀 때)
> 23호가 거리를 좁히는 상태. 타겟이 멀면 근접 대신 아래를 사용(거리 임계값·쿨 등 수치 TBD).
- **JumpAttack**: 
  해당 공격 발동 조건은 지정 거리 범위. 
  타겟 선정 조건은 가장 멀리 있는 플레이어. 
  타겟 탐색은 23호가 애니메이션 상 가장 높은 곳에 도달했을 때.
  타겟 선정 후 해당 위치에 두 개의 빨간 장판 생성.
  높은 곳에 도달했을 때, 지정 수치만큼 머무는 시간(JumpTime)을 가짐.
    빨간 장판1: 가장 아래에 위치해 있음. 바닥으로부터 0.01위에 생성. 빨간 장판2가 어디까지 커질 지에 대한 기준을 보여주며 알파값이 빨간 장판2에 비해 작아 흘리게 보임.
    빨간 장판2: 빨간 장판1 위에 위치할 예정이며 바닥으로부터 0.02위에 생성. 처음 장판1,2가 생성되었을 때, 장판2의 Scale은 0.1에서 시작. 지정 시간동안 장판2 크기와 동일해질 때까지 커짐.
    장판이 사라지면, 보스의 낙하 애니메이션 재생. 애니메이션 상 바닥에 도착했을 때, 장판 내에 있는 플레이어에게 지정 수치만큼 데미지 처리 후 장판 제거.
  도약과 하강은 특정 방향을 향한 이동없이 수직으로 이루어짐.
  최상단에 도달 시, mesh를 끄고 하강 시 mesh를 다시 켬으로써 순간이동 느낌을 줌.
- **DashAttack**: **타겟 방향으로 직선 돌진** → **경로상 플레이어 타격 + 넉백**. **벽 또는 대상과 충돌 시 정지**.

### 폭탄 (주기적, 원거리)
- 웰즈가 23호 위에서 **맵에 폭탄을 랜덤 살포**(주기적).
- 폭탄은 **플레이어의 기본 공격(좌클릭 평타)으로만 상호작용** 가능(스킬로는 안 됨).
- **기본 공격으로 맞으면**: 폭탄 위치와 때린 플레이어 위치로 **방향 벡터**를 만들어
  **때린 방향의 반대쪽으로 날아간다**. **날아가는 거리 = 입힌 피해량**에 비례.
- **비행 중 규칙**:
  - 추가 기본 공격이 들어와도 **무시(재연산 안 함)**.
  - **폭발 타이머(예: 5초)가 비행 동안 멈춤** → 날아가 **어딘가에 도착(정지)해야만 터짐**.
- **폭발 조건**: **벽 / 다른 플레이어 / 보스**에 부딪히면 터짐.
- **밀쳐냄(넉백)**: **보스는 안 밀림, 유저만 밀쳐짐.** 밀쳐진 유저는 **스킬 시전 취소 + hit 판정**.
- **폭탄은 터지면 화염 장판 생성 ** 만약 화염 장판 생긴곳에 추가로 폭탄이 터진다면 화염 장판 크기 증가.**.

### 송전기
- **유저 수에 따라 송전기 생성.**
- 제한시간 내 **파괴 실패 → 레이지 모드** / **파괴 성공 → 보스 그로기**.
- 송전기가 존재하는 동안 보스는 **차징 상태**로 돌입.

**차징**
- 빠른 쉴드 재생.
- 보스 주위 **근접 시 데미지 + 뒤로 밀치기**.

**레이지 모드**
- 전기를 두르고 **돌진 공격 3번**.

## 페이즈 (고정 패턴)
- **총 3페이즈**. 체력 **66% / 33%** 두 지점에서 전환.
- 전환 규칙: 보스는 매 상태 종료 시 "다음 패턴 선택" 로직이 있는데, **임계값을 넘는 순간 그 선택을 무시하고
  무조건 고정 패턴으로 진입**한다(현재 행동은 끝까지 수행한 뒤 전환).
- **고정 패턴 내용 = 송전기/차징 시퀀스** (양 임계값 공통, 세부 수치만 차등 가능):
  1. 보스가 **중앙에서 차징하며 대기**.
  2. 보스 주변 **강력한 전기 장판** → **근접 시 3초 내 즉사 수준** 데미지 = 사실상 **원거리만 보스 공격 가능** 구간.
  3. 차징 중 **보스 실드 HP 점증**.
  4. **사이드 4개 지점 중 인원수만큼 송전탑 생성** (1인 1 / 2인 2 / 3인 4).
  5. 제한시간 내 전부 파괴 **성공 → 보스 그로기** / **실패 → 레이지(강화 + 전기 이펙트 + 돌진 반복)**.

## 미정(밸런스/추후 확정)
- 근접↔원거리 **상태 전환 거리 임계값**, JumpAttack/DashAttack 쿨·데미지·AoE 범위.
- 제한시간, 실드 점증 속도, 돌진 횟수/데미지.
- 페이즈별 차등 수치.

## 23호 상태(FSM / 애니메이션) 목록 — 코드 `TwentyThreeState` 기준
`Idle` · `Walk` · `HookAttack` · `UpperAttack` · `Grab` · `JumpAttack` · `DashAttack` · `Charging` · `Groggy` · `Break` · `Dead`
- **Groggy** = 그로기, **Break** = 그로기 강화. **Charging** = 송전기 페이즈 차징. **Dead** = 사망.
- **Hit(피격)은 FSM 상태가 아님** — 애니 없이 **색깔만 변경**으로 처리(그래서 enum에 없음).
- 폭탄(웰즈)·송전탑 생성·레이지·페이즈 전환은 위 상태에 **얹히는 로직**으로 처리.
