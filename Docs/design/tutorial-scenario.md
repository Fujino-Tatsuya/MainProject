### 1.2 공통 사실
- 몬스터는 **맵 생성 때 서버가 모든 존에 한꺼번에 스폰**하고 바로 활성이다. 휴면·웨이브·진입 스폰 없음. 인지는 반경 판정이라 **벽 뒤도 본다**.
- 존 진입 감지, 존 클리어 판정, 길 막기 장치가 **하나도 없다**(`ClearCondition` enum 은 선언만). 지금은 시작부터 보스 진입까지 **자유 통행**.
- 튜토리얼 안내·목표·자막·토스트 UI 가 **없다**. 특성 선택 시스템도 **없다**(§6).
- 영혼(Soul)을 되살리는 정식 경로는 **타이머 만료 강제 부활뿐**이다(그 외 F10 디버그 키). 패드로 이동하면 영혼은 **부활 없이** 따라간다.
- 멀티는 1~3인, 리슨 서버, 게임 시작 후 난입·재접속 없음, 중도 이탈 허용(세션 계속). **일시정지 없음**(솔로 포함). 플레이어 이동은 **오너 권한**이라 서버가 원격 플레이어 이동을 보지 않는다.
- **Stage1 = 튜토리얼 = 지금의 모든 판**(Start → 항상 튜토리얼, T1). 튜토리얼용으로 바꾸는 공용 규칙(타이머·패드 등)은 사실상 본게임 규칙이 된다.

## 2. 공통 규칙

### 2.1 진행 단위 — "개인 체크리스트 + 파티 게이트"
- **배울 것(체크리스트)은 개인별**로 센다: 이동·대시·평타·패시브 툴팁·Q·E·특성 선택. 존3 간파 3번은 스피너봇 1마리를 함께 쓰므로 **파티 합계**로 센다(D2-1 확정).
- **길(게이트)은 파티 공동**이다: 문 개방·몬스터 기상·타이머·다리는 모두 한 맵을 공유하므로 서버가 한 번 판정한다.
- "전원" = **접속 중이고 완전 사망(PermanentDead)이 아닌 플레이어**. 누가 나가면 남은 인원 기준으로 다시 판정한다.
- **교착 방지**(논의 D9): 개인 체크리스트가 걸린 게이트(G1·G2·G4·G7·G10)는 **첫 완료자가 나온 뒤 60초**(조정값)가 지나면 자동으로 열린다. 열리기 전에는 "동료 대기 중 (1/2) · 자동 진행 0:45" 를 보여 준다.
- 튜토리얼이 재는 시간(교착 방지·자동 부활·자막)은 **서버 실제 시간**으로 잰다(간파 슬로우모션의 영향을 받지 않게).

### 2.2 길 막기와 몬스터 휴면
- 각 복도의 **앞 존 쪽 입구**에 "막힘 배리어"를 둔다. 해당 존 목표를 마치면 열린다.
- 특성 복도(복도1~4 전부)는 **다음 존 쪽 출구**에도 배리어를 둔다. 전원 특성 선택이 끝나면 열린다.
- **특성 선택 창이 열려 있는 동안 그 플레이어는 피해를 받지 않는다.** 복도1~3 은 휴면 덕분에 안전하지만, 복도4 는 존4 를 전멸시키지 않고 넘어오므로 남은 몬스터가 따라올 수 있다.
- 배리어는 **눈에 보여야** 한다(레이저/홀로그램 벽 등 — 아트 결정). 투명 벽은 "버그로 막혔다"로 읽힌다.
- 배리어는 **모든 플레이어 화면에서 막혀야** 하고(이동이 오너 권한이라 서버에만 있으면 통과된다), **몬스터도** 넘지 못해야 한다(넉백·스피너봇 돌진으로 밀려나가면 안 됨). 대시로도 통과할 수 없어야 한다.
- 추락 복구가 배리어 너머 바닥으로 사람을 옮기면 안 된다(현재 복구 후보는 착지점만 검사한다).
- **몬스터는 자기 차례가 올 때까지 휴면**한다. 휴면 = 인지·추격·공격 안 함 **+ 피해·넉백·CC 무시(무적)**. 배리어 너머에서 쏘는 원거리 공격(거너 평타 14m·Q 최대 16m, 대상 지정 R)이 있으므로 "배리어 덕분에 안 맞는다"에 기대지 않는다.
  - 존2: 진입 안내가 끝난 뒤 기상(§3.3).
  - 존3: 스피너봇은 G4 전까지 휴면 → 존3 첫 진입 때 **연습 모드**(§3.5) → 간파 3회(G5) 뒤 **본 모드**.
  - 존4: 설정 설명이 끝나고 타이머가 시작된 뒤 기상(§3.7). **중간보스는 다리가 열릴 때까지 휴면**(다리 개통 전 바깥에서 원거리로 잡는 것 방지).

- 우측 하단은 이미 **타이머 · 미니맵 · 키가이드**로 차 있다 → 쓰지 않는다.
- 죽거나 관전 중에도 목표 패널은 보이게 한다(지금 전투 HUD 레이어는 사망 연출·완전 사망 때 숨는다). → 논의 D15
- 늦게 로드된 클라도 **현재 단계 값으로 안내를 다시 그린다**(지나간 자막은 생략, 목표 패널은 현재 것).
- 문구는 기획이 직접 고칠 수 있게 **ID 로 관리**한다(§5). xlsx(`[DataTableText]`) 경로가 이미 있다.

### 2.4 캐릭터별 문구
캐릭터 3종(팔라딘·거너·어쌔신)의 Q·E·우클릭·패시브가 전부 다르다. **공통 문구 + 캐릭터별 한 줄 힌트** 구조로 쓴다(§5). 스킬 이름은 툴팁 `displayName` 을 끼운다(단, 이름을 끼우면 문장이 어색해지는 곳은 이름 없이 쓴다).

### 2.5 사망·부활 (논의 D5)
- **타이머 시작 전(존1~3·복도, 단계 기준)**: 사망 3초 뒤 **목숨 차감 없이** 지금 단계 구간의 안전한 지점(몬스터 인지 범위 밖)에서 부활 + 짧은 무적(2초).
- **타이머 시작 후(단계 기준 — 위치와 무관하게 전원)**: 사망 3초 뒤 같은 방식으로 자동 부활하되 **목숨 1개 차감**. 목숨 0이면 완전 사망(관전). 전원 완전 사망 → 결과 화면(기존).
  - 이유: 지금 영혼을 살리는 길은 타이머 만료뿐이다. 솔로가 존4에서 죽으면 타이머가 다 찰 때까지 아무것도 못 하고, 멀티에서는 동료가 패드를 밟는 순간 **영혼째로 보스방에 끌려가 보스전 내내 영혼**으로 남는다.
  - "위치 기준"으로 정하면 존4 몹을 복도3으로 끌고 와 싸우는 것만으로 목숨 차감이 사라진다 → **단계 기준**.
- 자동 부활을 기다리는 중에 패드·강제 이동이 시작되면 → 대기 중인 부활을 취소하고 **그 자리에서 즉시 부활**해 함께 이동(교육 단계면 목숨 차감 없음). 이동 뒤에 옛 구간으로 끌려가면 안 된다.
- 보스 등장 연출 잠금 중에는 생명주기 전이가 막혀 있다 — 이때 부활이 조용히 실패하지 않게 처리할 것.
- 존2 바닥 물 구멍 추락은 기존 추락 복구를 따른다(존3 M_typeC 에는 물 구멍이 없다).

### 2.6 용어
- 화면 용어는 **"간파"**(키가이드 "간파스킬", 툴팁 "간파"). 처음 한 번만 "간파(인터럽트)"로 병기한다. → 논의 D16

### 2.7 현재 키

### 3.1 존1 — 기본 조작 + 패시브
존1 은 몬스터 0인 안전 구역이다. **평타 연습용 허수아비 3개**를 둔다(간파 노랑 사이클이 없는 일반 허수아비 — 노랗게 빛나면 존3 신호와 헷갈린다). → 논의 D10

| 순서 | 보여 줄 것 | 완료 조건(개인) | 비고 |
|---|---|---|---|
| Z1-1 이동 | [목표] `TUT_Z1_MOVE` | 이동 거리 누적 5m | 이동은 오너 권한 — 판정 방법은 프로그래머 재량(§7.2) |
| Z1-2 대시 | [목표] `TUT_Z1_DASH` + [자막] `TUT_Z1_DASH_SUB` | 대시 1회 | 유저 요청 "기본적인 움직임"에 포함(논의 D11) |
| Z1-3 기본 공격 | [목표] `TUT_Z1_ATTACK` (0/5) | 허수아비에 기본 공격 **적중 5회** | 거너: 계속 쏘면 과열로 공격이 잠긴다 → 과열 1단계 이상이 되면 [자막] `TUT_Z1_ATTACK_GUNNER` |
| Z1-4 패시브 툴팁 | [목표] `TUT_Z1_PASSIVE` · [강조] 스킬바 맨 왼쪽 **P 칸** 펄스 | 패시브 툴팁이 **표시된 채 1초 유지** | 0.15초 호버 후 뜬다. 스치기만 하면 완료 안 됨. Shift 상세는 선택 안내 |

- 스킬 칸에 마우스를 올린 동안은 좌클릭 공격이 막힌다(기존 동작). Z1-4 는 공격 단계 뒤라 문제없다.
- Q·E·R·우클릭은 잠그지 않는다(슬롯별 잠금 기능이 없음 — 논의 D12). 팔라딘·거너 R 은 대상 지정 모드라 좌클릭이 "대상 확정"으로 바뀐다 — 존1에서 R 을 누르면 [자막] `TUT_TIP_R_CANCEL` 을 1회 띄운다.

### 3.2 복도1 — 특성 선택 + 특성 설명

### 3.5 존3 — 간파(인터럽트): 스피너봇 자체로 3번 (D2 확정)
존3 은 길쭉한 방(20×40)이고 **스피너봇이 출구 쪽 끝**(입구에서 약 35m)에 있다. 스피너봇은 두 단계로 싸운다.

| 단계 | 스피너봇 동작 | 플레이어가 하는 일 | 끝나는 조건 |
|---|---|---|---|
| **연습 모드** | 죽지 않는다(체력이 줄지 않음) · **회전 공격만** 한다 · 회전 공격 직전 간파 창(노랑)을 **매번** 연다 · 창은 **일정 간격**(권장 9초)으로 · 간파를 놓치면 회전 돌진은 **밀쳐내기만, 피해 없음** · 자기 자리에서 멀리 벗어나지 않는다 | 노랗게 빛날 때 바짝 붙어 우클릭 | 간파 **파티 합계 3번** (D2-1 확정) = **G5** |
| **본 모드** = "본격 전투" | 원래 스피너봇(모든 공격, 피해 있음, 체력 감소). 간파 창은 원래대로 회전 공격 직전 40% 확률·쿨 6초 | 처치. 노란빛이 보이면 간파(권장, 조건 아님) | 처치 = **G6** |

| 순서 | 트리거 | 보여 줄 것 | 완료 조건 |
|---|---|---|---|
| Z3-1 | 첫 플레이어 존3 진입 | 스피너봇 **연습 모드 시작** · [자막] `TUT_Z3_INTRO` → `TUT_Z3_PRACTICE_NOTE` · [강조] 스피너봇 + 스킬바 우클릭 칸 | — |
| Z3-2 | 연습 중 | [목표] `TUT_Z3_GOAL` (간파 ■□□ 0/3) · 거너는 [자막] `TUT_Z3_GUNNER` | — |
| Z3-3 | 간파가 아무것도 못 맞혔을 때 | [자막] `TUT_Z3_MISS` | — |
| Z3-4 | 노랑이 아닐 때 스피너봇을 간파로 맞혔을 때 | [자막] `TUT_Z3_EARLY` | — |
| Z3-5 | 간파 성공할 때마다 | 진행도 1칸 · 첫 성공만 [자막] `TUT_Z3_FIRST_SUCCESS` | — |
| Z3-6 | 간파 창을 연속 4번 놓쳤을 때(조정값) | [자막] `TUT_Z3_HINT` (요령 다시 안내) | — |
| Z3-7 | **3번 달성 = G5** | 스피너봇 잠깐 멈춤(약 2초) · [자막] `TUT_Z3_REAL` · [목표] `TUT_Z3_BOSS` · 스피너봇 체력 바 활성 | **본 모드 시작 = "본격 전투"** |
| Z3-8 | 스피너봇 처치 | [자막] `TUT_ZONE_CLEAR` | **G6 복도3 입구 개방** |

- **연습 모드에서 죽지 않게 하는 이유**: 스피너봇 체력은 3200(xlsx)이라 파티가 몰아치면 3번 간파 전에 잡힌다. 그러면 "3번 채울 때까지 본격 전투를 시작하지 않는다"가 깨진다. 연습 중임을 알 수 있게 체력 바를 회색·잠금 표시로 둔다.
- **창 간격 9초를 권장하는 이유**: 간파 재사용 대기시간이 8초(xlsx 3캐릭터 공통)다. 간격이 이보다 짧으면 쿨 중에 창이 열려 "노랑인데 못 누른다"가 생긴다. 지금 스피너봇은 확률 40%·쿨 6초라 창이 언제 올지 몰라 연습이 늘어진다. 솔로 3번 = 최소 약 27초, 실수 포함 약 45~60초.
- **창 길이**는 원래 값(약 1.9초 = 저작 1.5초 ÷ 공격속도 0.8)을 그대로 쓴다. 연습에서 익힌 타이밍이 본 모드와 같아야 한다. 너무 어렵다면 연습 모드만 늘린다(튜닝값).
- 실패 원인은 대부분 **거리·방향**이다(간파는 전방 근접 판정, 시전 때 마우스 방향으로 몸을 돌림). 문구는 "바짝 붙어서, 마우스를 스피너봇에 두고"를 강조한다. 거너 간파는 판정 뒤 1.5m 밀려나므로 다시 붙어야 한다.
- 간파 창 하나에는 **성공 1번만** 인정된다(먼저 맞힌 사람이 가져감). 그래서 3번 = 창 3개가 필요하다.
  - **파티 합계 3번(D2-1 확정)**: 누가 성공하든 1칸씩 오른다. 솔로·멀티 모두 창 3개, 약 30~60초.
  - (참고 — 채택 안 함) 개인별 3번이면 3인일 때 창 9개(약 81초 이상)가 필요하고 서로 가로챈다.
- 성공하면 기존 동작대로 공격이 취소되고 약 1초 비틀거린다(그로기). 연습 중에는 이때 때려도 체력이 줄지 않는다.
- 노랑 표시는 판정 창보다 0.15초 먼저 꺼진다(기존 — 늦게 눌러 억울한 일을 막는 보정). 문구는 "노랗게 빛나는 **순간**"으로 쓴다.
- development 의 간파 슬로우모션은 지금 **허수아비에만** 연결돼 있다. 스피너봇에 연결할지는 선택(연결하면 성공 때마다 파티 전원이 느려진다) → 논의 D18.
- 스피너봇은 출구 약 5m 앞에 있다. 연습·본 모드 모두 회전 돌진이나 넉백으로 G6 배리어 너머(복도3)로 나가면 안 된다(§2.2).
- 이 연습 모드·본 모드 전환은 **몬스터 코드(경석 영역)** 변경이다 → 구현 시 `Docs/tech/handoff-*.md` 로 공유.

### 3.6 복도3 — 특성 선택(설명 없음)
복도2 와 같다. 복도3 중간 지점에서 창이 뜬다. 전원 선택(또는 교착 방지 자동 획득) → **G7 존4 입구 개방**.
- 존4 모서리 PeekABot(인지 12m)이 복도3 의 약 65%를 보지만, 존4 몬스터는 타이머 시작(G8)까지 휴면·무적이라 안전하다.
- 타이머는 아직 돌지 않는다(사망 시 목숨 차감 없음).

### 3.7 존4 — 설정 설명 → 타이머 → 패널 · 다리 · 중간보스
사용자 원안 순서: **존4 에서 타이머가 차오른다 → 짧은 설정 설명으로 타이머를 인지시킨다 → 패널·다리를 설명한다 → 다 클리어하면 보스방 안내.**
설명이 전투에 묻히지 않도록, **설명이 끝날 때까지 타이머와 존4 몬스터를 멈춰 둔다.**

| 순서 | 트리거 | 보여 줄 것 | 완료 조건 / 결과 |
|---|---|---|---|
| Z4-0 | **첫 플레이어 존4 진입**(G7 이후) | 우측 하단 **타이머 게이지가 처음 나타남**(빈 게이지, 펄스) · [자막] `TUT_Z4_LORE` → `TUT_Z4_TIMER_HINT` (파티 전원 화면에 동시에) | 존4 몬스터 휴면 유지, 타이머 정지 |
| Z4-1 | 설정 자막이 끝나면(약 8~10초) = **G8** | 타이머 **시작**(차오름) · [자막] `TUT_Z4_START` | — |
| Z4-2 | 직후 | [자막] `TUT_Z4_PANEL_INTRO` · [목표] `TUT_Z4_PANEL_GOAL` (제어 패널 0/4) · 패널 위 F 프롬프트(development 에 있음) | 3초 뒤 존4 몬스터 기상(중간보스 제외) |
| Z4-3 | 패널 하나 켜질 때마다 | [목표] 진행도 갱신(1/4…) · 첫 1회만 [자막] `TUT_Z4_PANEL_FIRST` | 누가 켜도 파티 공유(기존 동작) |
| Z4-4 | 4개 모두 → 다리 개통(1.5초) | [자막] `TUT_Z4_BRIDGE` · [목표] `TUT_Z4_MIDBOSS` · [강조] 가장 가까운 계단 → 다리 → 중앙 섬 | **중간보스 기상** |
| Z4-5 | 중간보스 전투 중 | (선택) [자막] `TUT_Z4_COUNTER_REMIND` · (선택) `TUT_Z4_ULT_*` | — |
| Z4-6 | **중간보스 처치** = **G9** | [자막] `TUT_Z4_CLEAR` · [목표] `TUT_Z4_GO_BOSS` · [강조] 미니맵 보스 아이콘 펄스 · **복도4 입구 배리어 개방** | 존4 클리어 = 중간보스 처치(일반 몹 전멸 아님, 논의 D4) |

- 다리는 1층이 아니라 **상·하 2층 통로**에서 중앙 섬(높이 약 2.9m)으로 이어진다. 2층은 계단으로 오르고, 그 위에 Humanoid 2·Mortar 1 이 있다. 마지막 패널은 1층 모서리에서 켜지므로 "계단으로 올라가 다리를 건너라"를 반드시 말해 준다.
- 패널 4개는 각 모서리 몬스터 무리 바로 안쪽에 있다 → 자연스럽게 "모서리 정리 → 패널 켜기" 동선이 된다.
- 다리 개통 순간 맵 전체 NavMesh 를 다시 굽는 설정(`rebakeNavMeshOnOpen=1`) 때문에 **수백 ms 끊김**이 날 수 있다. 연출 타이밍과 겹친다 — 프로그래머 확인 항목.
- 다리 고정 조각 2개는 열림 위치가 저작돼 있지 않아 실행마다 에러 로그가 찍힌다(거짓 경보 여부 확인).
- **타이머가 존4 도중 다 차면**: 기존 동작대로 3초 경고 → 전원 강제 이동. 그때 [자막] `TUT_TIMER_EXPIRED` 를 띄워 "버그가 아니라 설정"임을 알린다. 강제 이동은 패드·배리어와 무관하게 항상 동작해야 한다. 이 경우에도 튜토리얼 안내는 보스방 도착으로 정리한다(§3.9).
- 제한시간: 솔로 첫 플레이 추정 = 처치량 약 9,000HP(모서리 4무리 + 알람 2무리 + 2층 한쪽 + 중간보스 3,600) ÷ DPS 45~60 ≈ 150~200초 + 이동 약 35초 + 패널·다리·회피 → **250~330초**. 여기에 복도4 특성 선택(약 10~20초)도 타이머 안에 들어간다. 그래서 **420초**(D6 확정). 플레이테스트에서 너무 길거나 짧으면 그때 조정한다.

### 3.9 보스 진입 — 튜토리얼 안내 종료
| 순서 | 트리거 | 보여 줄 것 |
|---|---|---|
| B-1 | 패드 카운트다운 중 | [자막] `TUT_B_PAD_COUNT` (발판 밖으로 나가면 취소) — 3·2·1 은 기존 표시 |

- 패드는 존 경계에서 약 2.5m 안쪽부터라 "존에 들어서는 순간 = 카운트다운 시작"이다. 그래서 "1명이 밟으면 전원 이동" 경고(`TUT_B_PAD_WARN`)는 **G10 개방 시점(C4-3)에 파티 전원에게** 띄운다(복도4 출구 배리어가 열리는 순간 = 아직 아무도 패드에 못 간 시점). → 논의 D17
- 제때 도착하면 타이머가 멈추고 게이지가 비워진다(기존). "다 차기 전에 스스로 왔다"로 읽히므로 그대로 둔다.
- (선택) 보스 23호는 **정면 ±60°에서만** 간파된다. 스피너봇·중간보스는 방향 무관이라 학습이 어긋날 수 있다 → 보스방 도착 시 1줄 팁 여부. → 논의 D19

## 6. 특성(복도 선택) — 구현 제약 메모

> 🔴 **특성이 무엇인지(이름·풀·제시 장 수·무작위 여부·효과·중복 규칙·획득 표시)는 별도 "특성 기획서"가 원본이다**(D8 확정 — 공유 예정). 이 문서는 **튜토리얼에서 언제·어디서 고르는지**만 정한다. 아래는 특성 기획서를 구현할 때 부딪힐 **현재 코드 제약** 메모다.

- 특성 선택 시스템은 **코드에 없다**(특성·보상 선택·상점·BuildModifier 클래스 0). 문서상으로도 "로비에서 고르는 빌드/시그니처 특성"과 8월+ 초안의 "런 중 상점"만 있다. 복도 선택은 새 기능이다.
- 튜토리얼이 요구하는 최소 흐름: **복도 4곳**에서 각각 **카드 N장 중 1장**(개인 선택) → 서버 확인 → 효과 적용 → 획득 표시. 한 판에 특성 **4개**를 얻는다.
- 4번 고르므로 특성 기획서에 **중복 획득 규칙**(중첩 / 후보 제외)이 있어야 한다. 지금 스탯 배율은 (종류, 출처 id) 가 같으면 덮어써지므로, 중첩시키려면 특성마다 출처 id 를 달리해야 곱해진다.
- 지금 실효 배율이 2종뿐이라, 특성 기획서의 효과가 스탯 위주면 배선 작업(아래)이 먼저 필요하다.
- **지금 그대로 효과가 나는 스탯 배율은 공격력·이동 속도 2종뿐**이다.
  - 공격 속도·방어 배율은 값만 있고 **읽는 곳이 없다**(평타 속도·피해 경감이 기본값을 직접 씀).
  - 최대 체력 배율은 **HP 바 분모에만** 들어간다. 실제 체력 상한·회복·부활은 기본값이라, 고르면 체력은 그대로인데 바가 약 83% 로 보인다.
  - 세 가지를 쓰려면 배선 작업이 따로 필요하다(§7.2).
- 배율은 **1 이상만** 쓴다(1 미만은 디버프로 분류돼 보스방 진입 연출 때 지워진다). 사망·부활로는 지워지지 않는다.
- 비율 쿨감(예: 쿨 −10%)은 스킬 쿨 시작값을 SO 에서 직접 읽어 지금은 불가. "적중 시 Q 쿨 n초 감소" 같은 **이벤트형 쿨 감소**는 기존 서버 API(`ReduceCooldownServer`)로 가능하다.
- 획득한 특성을 **어디서 다시 보는지**가 필요하다(지금은 상태이상 HUD 에 `AttackDamage` 같은 내부 이름으로만 뜬다).

#### 7.1 정정 메모 (S0 코드 대조, 2026-10-11 `feature/TutorialStage`)
위 표 중 실제 코드와 다른 8건. 표는 원문 그대로 두고 여기서 바로잡는다.
1. 패시브 툴팁 "표시됨" — `visible` 은 `PassiveHUD` 가 아니라 `SkillTooltipView.cs:35` 의 private 필드다. displayKey `Passive` 는 슬롯 저작값이 아니라 `PassiveHUD.cs:46` 코드에서 Bind 한다.
2. `Player.ServerAttackLanded` 의 `AttackType` 에는 Default/SkillQ/SkillE/SkillR 외에 **None·Skill** 도 있다.
3. `CombatStatsEvents.ServerCounterSucceeded` 는 중간보스 3종 외에 **WallBot** 도 발행한다. 23호는 이 이벤트가 아니라 `ReceiveAttack` 자체 경로다.
4. 간파 "맞힌 수" 를 밖에서 받을 **공개 훅이 없다** — `PlayerInterruptSkillBase.OnInterruptResolutionCompleted` 는 protected(빗나감 문구 S9 는 훅 추가 필요).
5. `TrainingDummy.prefab` 은 `TrainingDummyInterrupt` + 내부 순수 `TrainingDummyInterruptCycle` 구조이고 `_Elite`·`_Boss` 변형이 있다(존1 용 "사이클 없는 변형"은 새로 만든다).
6. 보스 진입 패드 크기 — **씬 값 15×15**, 코드 기본값은 6×6.
7. 로컬 입력 차단은 `UiInputGateManager` 에서 끝나지 않는다 — 실제로 막는 곳은 `PlayerUiInputPolicy`(`BlockedChanged` 구독) → `PlayerInputReader.SetUiInputSuppressed`. 전체 사슬 = `UiModalBlocker` → `UiInputGateManager` → `PlayerUiInputPolicy` → `PlayerInputReader`.
8. `InteractPrompt`(패널 F 프롬프트)는 development 전용이 아니라 **이 브랜치에 이미 있다**.

> 진행 상태 코어(§7.2-1)는 S1 에서 구현 — [../tech/tutorial-director.md](../tech/tutorial-director.md) (`TutorialDirector`·`TutorialFlowModel`·`TutorialStageMarker`).

### 7.2 새로 필요한 것
1. **튜토리얼 진행 상태**(서버 소유, 복제) — 단계·개인 체크리스트·게이트 상태. 존 프리팹은 비네트워크라 씬 상주 객체가 필요.
2. **구간 진입 감지**(존1~4, 복도1~4 중간) — 기존 벽 투명화 트리거는 클라 로컬 연출용이고 옆 존까지 덮어서 그대로 못 쓴다.
3. **개인 체크리스트 판정** — 이동 거리(오너 권한이라 오너 → 서버 보고 등 필요) · 대시(서버 승인 지점) · 패시브 툴팁 "표시됨"(지금 `visible` 이 private, 클라 로컬 → 서버 보고) · 스킬 "사용"(Q·E — E 계열은 적중 이벤트가 안 난다) · 간파 성공/빗나감.
4. **배리어**(G1~G4·G6·G7·G9·G10) — 모든 피어에서 막힘(이동이 오너 권한), 몬스터도 막힘(NavMesh), 대시 통과 불가, 개방 상태 복제·늦은 클라 재적용. 공용 존 프리팹이 아니라 튜토리얼 쪽에 둘 것. 추락 복구 후보가 배리어 너머로 잡히지 않게.
5. **몬스터 휴면/기상**(존 단위 + 중간보스 개별) — 휴면 = 인지·공격 안 함 + 무적.
6. **존 클리어 판정**(존2 전멸, 존3 스피너봇, 존4 중간보스) — 몬스터를 존별로 묶는 장부가 없다.
7. **타이머 지연 시작** — 자동 시작 끄기 + 서버 시작 API + Idle 때 HUD 숨김. 만료 유지·도착 정지·영혼 강제 부활 계약은 지킬 것(경석 영역). **Stage1 이 모든 판이라 본게임에도 적용됨**(D1).
8. **보스방 길 잠금**(D3 확정) — 복도4 입구 배리어(중간보스 처치 시 개방) + 복도4 출구 배리어·보스 진입 패드 비활성(복도4 특성 전원 선택 시 개방). 타이머 만료 강제 이동은 막지 말 것. Stage1 이 모든 판이므로 튜토리얼 스테이지에만 적용되게.
9. **튜토리얼 사망 규칙**(§2.5) — 자동 부활(단계 기준 목숨 차감 여부), 부활 지점·무적, 이동 중 대기 부활 취소, 연출 잠금 중 처리.
10. **존1 평타 허수아비**(간파 사이클 없는 변형) — 허수아비 프리팹 수정은 Debug 연습장에도 영향 → 변형으로.
15. **스피너봇 연습 모드 → 본 모드**(§3.5) — 연습 모드: 체력 감소 없음 · 회전 공격만 · 창 매번·고정 간격 · 돌진 피해 없음(밀쳐내기만) · 자리 유지. 간파 3번(서버 집계) 뒤 본 모드. **몬스터 코드 = 경석 영역** → handoff 문서로 공유. 튜토리얼 스피너봇에만 적용(다른 스피너봇·절차 맵에 퍼지지 않게).
11. **안내 UI**(목표 패널·자막·강조) — 사망·관전 중에도 보이게, 늦은 클라 재구성.
12. **특성 선택**(§6) — 복도 4곳 · 데이터·카드 UI·선택 RPC·서버 검증(제시된 후보인지, 이미 골랐는지)·획득 표시·자동 획득(교착 방지·타이머 만료) · **선택 창이 열린 동안 무적** · 중복 획득 규칙.

## 9. 완료 기준 (QA 체크리스트)

- [ ] 솔로 × 3캐릭터: 존1 → 보스방 도착까지 막힘 없이 진행, 각 단계 문구가 캐릭터에 맞게 나온다(어쌔신은 분노 게이지 기준).
- [ ] 존1~3 에서 길을 건너뛸 수 없다(배리어 — 걷기·대시·추락 복구 모두). 존4 에서 중간보스 전에 복도4 로, 복도4 특성 전원 선택 전에 패드로 갈 수 없다(D3) — 그래도 타이머 만료 강제 이동은 정상.
- [ ] 휴면 몬스터는 배리어 너머 원거리 공격(거너 평타·Q·R, 팔라딘 R)에 피해·넉백을 받지 않는다. 다리 개통 전 중간보스를 원거리로 잡을 수 없다.
- [ ] 복도1~4 특성 선택이 각 1번씩 뜨고(설명은 복도1 만), 선택 창이 열린 동안 피해를 받지 않는다. 특성 4개가 실제 수치에 반영되고(중복 규칙대로) 보스전까지 유지된다.
- [ ] 복도4: 고르는 동안 타이머가 계속 찬다. 고르는 도중 타이머가 다 차면 창이 닫히고 무작위 1장 획득 후 강제 이동된다.
- [ ] 존3: 간파 3번 전(연습 모드)에는 스피너봇이 죽지 않고, 회전 공격만 하며, 창이 매번·일정 간격으로 열리고, 피해를 주지 않는다. 빗나감·이른 간파 문구가 뜬다. 3번 뒤 본 모드로 바뀌고 처치해야 복도3 이 열린다. 회전 돌진·넉백으로 복도3 으로 넘어가지 않는다.
- [ ] 존3 멀티: 간파 합계가 파티 공통으로 오르고(누가 성공했는지 무관), 한 창에 두 명이 동시에 눌러도 1번만 센다.
- [ ] 타이머는 존4 진입 + 설정 자막 뒤에 처음 차오른다. 존1~3 에서 아무리 오래 있어도 강제 이동이 없고, HUD 틀도 안 보인다.
- [ ] 존4 에서 시간 초과 → 문구 + 강제 이동 정상, 보스방 도착 시 튜토리얼 안내 정리.
- [ ] 사망: 타이머 전에는 목숨 그대로 부활, 후에는 목숨 차감 부활. 부활 대기 중 패드·강제 이동이 일어나도 옛 구간으로 끌려가지 않는다.
- [ ] MPPM 2~3인: 개인 체크리스트·대기 표시·교착 방지 60초·특성 각자 선택·늦게 도착한 사람에게 창 재표시 없음·패널 공유·타이머 동일·설정 자막 전원 동시.
- [ ] 중도 이탈: 게이트가 남은 인원 기준으로 다시 판정된다.
