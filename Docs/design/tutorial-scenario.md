### 1.2 공통 사실
- 몬스터는 **맵 생성 때 서버가 모든 존에 한꺼번에 스폰**하고 바로 활성이다. 휴면·웨이브·진입 스폰 없음. 인지는 반경 판정이라 **벽 뒤도 본다**.
- 존 진입 감지, 존 클리어 판정, 길 막기 장치가 **하나도 없다**(`ClearCondition` enum 은 선언만). 지금은 시작부터 보스 진입까지 **자유 통행**.
- 튜토리얼 안내·목표·자막·토스트 UI 가 **없다**. 특성 선택 시스템도 **없다**(§6).
- 영혼(Soul)을 되살리는 정식 경로는 **타이머 만료 강제 부활뿐**이다(그 외 F10 디버그 키). 패드로 이동하면 영혼은 **부활 없이** 따라간다.
- 멀티는 1~3인, 리슨 서버, 게임 시작 후 난입·재접속 없음, 중도 이탈 허용(세션 계속). **일시정지 없음**(솔로 포함). 플레이어 이동은 **오너 권한**이라 서버가 원격 플레이어 이동을 보지 않는다.
- **Stage1 = 튜토리얼 = 지금의 모든 판**(Start → 항상 튜토리얼, T1). 튜토리얼용으로 바꾸는 공용 규칙(타이머·패드 등)은 사실상 본게임 규칙이 된다.

## 2. 공통 규칙

### 2.1 진행 단위 — "개인 체크리스트 + 파티 게이트"
- **배울 것(체크리스트)은 개인별**로 센다: 이동·대시·패시브 툴팁 + 존1 기본 공격·Q·E·R·우클릭 각각 사용 1회 + 특성 선택. 존3은 **간파 → 취약 밀치기 → 벽 충돌 연계 성공을 파티 합계 3회**로 집계한다. 개인별 성공 횟수 조건은 없다.
- **길(게이트)은 파티 공동**이다: 문 개방·몬스터 기상·타이머·다리는 모두 한 맵을 공유하므로 서버가 한 번 판정한다.
- "전원" = **접속 중이고 완전 사망(PermanentDead)이 아닌 플레이어**. 누가 나가면 남은 인원 기준으로 다시 판정한다.
- **교착 방지**(논의 D9): 특성 선택 게이트(G2·G4·G7·G10)는 **첫 완료자가 나온 뒤 60초**(조정값)가 지나면 자동으로 열린다. **G1은 제외**: 모든 공격·스킬 사용이 필수이므로 시간 경과로 완료 처리하지 않는다. 존1에서는 미완료 항목과 동료 진행도를 표시하고 힌트로 지원한다.
- 튜토리얼이 재는 시간(교착 방지·자동 부활·자막)은 **서버 실제 시간**으로 잰다(간파 슬로우모션의 영향을 받지 않게).

### 2.2 길 막기와 몬스터 휴면
- 각 복도의 **앞 존 쪽 입구**에 "막힘 배리어"를 둔다. 해당 존 목표를 마치면 열린다.
- 특성 복도(복도1~4 전부)는 **다음 존 쪽 출구**에도 배리어를 둔다. 전원 특성 선택이 끝나면 열린다.
- **특성 선택 창이 열려 있는 동안 그 플레이어는 피해를 받지 않는다.** 복도1~3 은 휴면 덕분에 안전하지만, 복도4 는 존4 를 전멸시키지 않고 넘어오므로 남은 몬스터가 따라올 수 있다.
- 배리어는 **눈에 보여야** 한다(레이저/홀로그램 벽 등 — 아트 결정). 투명 벽은 "버그로 막혔다"로 읽힌다.
- 배리어는 **모든 플레이어 화면에서 막혀야** 하고(이동이 오너 권한이라 서버에만 있으면 통과된다), **몬스터도** 넘지 못해야 한다(넉백·스피너봇 돌진으로 밀려나가면 안 됨). 대시로도 통과할 수 없어야 한다.
- 추락 복구가 배리어 너머 바닥으로 사람을 옮기면 안 된다(현재 복구 후보는 착지점만 검사한다).
- **몬스터는 자기 차례가 올 때까지 휴면**한다. 휴면 = 인지·추격·공격 안 함 **+ 피해·넉백·CC 무시(무적)**. 배리어 너머에서 쏘는 원거리 공격(거너 평타 14m·Q 최대 16m, 대상 지정 R)이 있으므로 "배리어 덕분에 안 맞는다"에 기대지 않는다.
  - 존2: 진입 안내가 끝난 뒤 기상(§3.3).
  - 존3: G4 전 휴면 → 간파·취약 밀치기·벽 충돌 연계 연습 → 성공 3회 및 마지막 원위치 복귀(G5) 뒤 **본 모드**(§3.5).
  - 존4: 설정 설명이 끝나고 타이머가 시작된 뒤 기상(§3.7). **중간보스는 다리가 열릴 때까지 휴면**(다리 개통 전 바깥에서 원거리로 잡는 것 방지).

### 3.1 존1 — 기본 조작 + 모든 공격·스킬 사용

| 순서 | 보여 줄 것 | 완료 조건(개인) | 비고 |
|---|---|---|---|
| Z1-1 이동 | [목표] `TUT_Z1_MOVE` | 이동 거리 누적 5m | 이동은 오너 권한 — 판정 방법은 프로그래머 재량(§7.2) |

| Z1-3 기본 공격 | [목표] `TUT_Z1_ATTACK` (0/1) | 기본 공격 **실제 실행 1회** | 적중은 필수 아님. R 대상 확정용 좌클릭은 기본 공격으로 세지 않음 |

| Z1-7 우클릭 | [목표] `TUT_Z1_RMB` | 우클릭 스킬 실제 사용 1회 | 간파 성공은 요구하지 않음. 존3에서 따로 교육 |
| Z1-8 R | [목표] `TUT_Z1_R` · 캐릭터별 R 힌트 | R 실제 사용 1회 | 팔라딘·거너는 대상 확정 후 발동, 어쌔신은 변신 진입. 자원 부족·취소는 미완료 |
| Z1-9 마무리 | [목표] 공격·스킬 사용 체크 5종 완료 + `TUT_Z1_GO` | 접속 중 유효 플레이어 전원 존1 체크 완료 | **G1 복도1 입구 개방**. 시간 경과로 사용 조건을 생략하지 않음 |

- 기본 공격·Q·E·R·우클릭은 **서로 다른 5개 항목**으로 각각 1회만 센다. 버튼 입력이 아니라 실제 발동 기준이며, 쿨타임 중 거부·실패·조준 취소는 세지 않는다.
- 존1에서 먼저 사용한 스킬도 기록한다. 안내 순서와 상관없이 미리 사용한 항목은 완료 상태로 표시하며 다시 사용시키지 않는다. 사용 완료는 사망·부활로 되돌리지 않는다.
- 어쌔신은 허수아비를 공격해 분노를 모은 뒤 R을 사용한다. 허수아비는 분노 획득이 가능한 대상으로 유지한다. R 사용 전에는 `TUT_Z1_R_ASSASSIN`으로 분노 준비를 안내한다.
- 일반·변신 Q/E를 별도 항목으로 추가하지 않는다. Q·E 각 항목에 대해 어느 형태든 실제 사용 1회면 인정하는 것을 기본안으로 둔다.
- 기존 이동·대시·패시브 확인 조건은 유지한다. 패시브는 능동 사용 스킬 5종에 포함하지 않는다.

- 순서를 "평타 → 패시브"로 둔 이유: 팔라딘 패시브(불굴의 의지)는 스폰 때 준비 상태라 **첫 평타 적중에서 발동**한다(허수아비에 맞아도 발동, 상자는 아님). 방금 본 효과를 툴팁으로 확인시키는 흐름이 된다.
- 스킬 칸에 마우스를 올린 동안은 좌클릭 공격이 막힌다(기존 동작). Z1-4 는 공격 단계 뒤라 문제없다.
- Q·E·R·우클릭은 잠그지 않는다(슬롯별 잠금 기능이 없음 — 논의 D12). 팔라딘·거너 R 은 대상 지정 모드라 좌클릭이 "대상 확정"으로 바뀐다 — 존1에서 R 을 누르면 [자막] `TUT_TIP_R_CANCEL` 을 1회 띄운다.
- 허수아비는 거너 R의 유효 타깃으로 지정 가능해야 한다. 표적을 고를 수 없으면 R 사용 조건이 막히므로 QA에서 확인한다.

### 3.2 복도1 — 특성 선택 + 특성 설명

- 선택 창이 떠 있는 동안 그 플레이어는 움직일 수 없지만, 배리어·휴면 덕분에 복도는 안전하다.
- 창을 닫고 나중에 고르기는 없다(복도를 못 나가므로). 교착 방지 자동 진행이 발동하면 **열려 있던 창은 닫히고, 미선택자는 무작위 1장을 자동 획득**한다(논의 D14).
- 게이트가 열린 뒤나 자동 획득을 받은 플레이어에게는 창을 **다시 띄우지 않는다**(늦게 도착한 낙오자가 존2가 깨어난 뒤 입력이 막힌 채 맞는 것 방지). 왕복해도 다시 뜨지 않는다.
- 쿨타임 초기화 범위는 Q·E·R·우클릭과 대시이며, 일반/변신 쿨타임을 별도로 보관하는 경우 양쪽 모두 초기화한다. 스킬 자원(분노·과열), 체력·패시브 내부 주기는 초기화하지 않는다.
- 첫 진입한 1명 때문에 다른 동료까지 미리 초기화하지 않는다. 각자 복도1에 첫 진입할 때 적용하고, 왕복·부활로 재진입해도 반복하지 않는다.
- **추가 구현 검토**: 진행 중인 행동의 종료 시점에 쿨타임이 생기는 어쌔신 R 등은 초기화 직후 종료하며 다시 쿨타임이 걸릴 수 있다. 해당 행동의 종료까지 초기화 예약을 유지하여, 존1에서 사용한 행동 때문에 존2에 잔여 쿨타임을 들고 가지 않도록 처리하는 것을 제안한다. 자원을 채우거나 변신을 강제 해제하는 의미는 아니다.

### 3.5 존3 — 간파 → 취약 밀치기 → 벽 충돌, 연계 3회 후 본 전투

#### 연계 성공·멀티 집계
- 성공은 **그 연계에서 간파 성공 → 취약 진입 → 우클릭 밀치기 → 유효 벽 충돌**이 모두 이어졌을 때 인정한다. 간파나 밀치기만으로는 0/3이 증가하지 않는다.
- 간파한 사람과 밀친 사람은 **달라도 되고 같아도 된다**. 중간에 여러 동료가 이어서 밀어도 인정한다. 역할 배정·개인별 성공 조건은 없다.
- 하나의 간파 창에는 성공 1번, 하나의 연계에는 벽 충돌 성공 1번만 인정한다. 동시 밀치기·벽 접촉 반복·연출 중 중복 이벤트로 횟수가 여러 번 오르지 않는다.
- **우클릭 밀치기로 발생한 충돌만** 집계한다. 빈 입력·일반 피해·Q 넉백·스피너봇 자기 돌진·복귀 이동 중 충돌·기존 벽 접촉은 성공으로 세지 않는다.
- 유효 벽은 맵의 연습용으로 지정한 벽이다. 상자·다른 몬스터·플레이어·출구 배리어 접촉은 벽 충돌 목표로 인정하지 않는다. 벽 충돌로 제압까지 만드는 것은 추가 조건이 아니다.
- 진행도·단계·성공 표시·다음 기회는 파티 공유. 사망·중도 이탈로 이미 성공한 연계 횟수를 초기화하지 않는다.

#### 취약 유지와 쿨타임
- 교육 중 간파 성공 후에는 **벽 충돌에 성공할 때까지 취약 상태가 시간으로 종료되지 않는다**. 잠깐의 진입 기절이 끝나도 스스로 이동·추격·공격하지 않는다. 우클릭 밀치기에 의한 이동은 허용한다.
- 간파 성공마다 파티 전원의 우클릭 쿨타임을 **그 단계 진입 때 1회만** 초기화한다. 밀치기 실패·빗나감마다 계속 초기화하지 않는다. 실패 후에는 정상 쿨타임을 기다려 다시 위치를 잡고 밀 수 있다.
- 간파를 놓치면 간파 예고를 다시 제공한다. 준비 단계의 반복 기회는 기존 권장 간격 9초를 출발점으로 튜닝하되, 취약·복귀 단계에서는 새 간파 공격을 예고하지 않는다. 원위치 복귀가 끝났어도 우클릭이 준비되지 않은 상황에서 다음 기회를 강제하지 않도록 간격을 조정한다.
- 취약 신호와 간파 가능 신호를 구분한다. 밀치기 단계에서는 '노란빛을 기다리라'는 안내 대신 '벽 반대편에서 다시 우클릭'을 안내한다.

#### 연습 위치·복귀·전투 전환
- 연습 위치는 **우클릭 밀치기 1~2회로 유효 벽에 닿는 거리**에 잡는다. 본 전투 시작 위치도 이 위치를 사용한다. 벽과 밀기 방향을 시각적으로 안내한다.
- **매 성공 후(3회째 포함) 원위치로 복귀**한다. 벽에 붙은 상태로 다음 연습을 시작하지 않는다. 순간이동보다 짧은 회복·복귀 이동으로 전환을 보여 준다.
- 복귀 중에는 공격하지 않고, 피해·외부 밀치기를 무시하며 일반 추격도 하지 않는다. 플레이어 몸 충돌에 막혀 복귀가 멈추지 않도록 **튜토리얼 대상에만 복귀 전용 처리**를 둔다. 파티원을 강제로 이동시키는 의미는 아니다.
- 교육 중 대상 체력은 감소하지 않으며 회색·잠금 체력 바로 표시한다. 정상 우클릭 밀치기 반응은 취약 단계에서 허용한다. 대상이 죽거나 배리어 너머로 밀려 교육이 막히지 않게 한다.
- 3회 성공 후 복귀 완료 시 '연습 완료' 안내를 보여 주고 **정상 체력·정상 공격·정상 취약 지속시간·정상 쿨타임 규칙**으로 본 전투를 시작한다. 교육용 무한 취약·정지·무적·쿨타임 초기화는 이후 적용하지 않는다.
- 본 전투 체력과 패턴은 현재 밸런스 데이터를 따른다. 본 전투 도중 간파나 벽 충돌을 다시 3회 요구하지 않는다. 처치하면 복도3을 연다.
- 간파 창 길이는 본 전투와 같은 값을 출발점으로 사용한다. 구체적인 연습 위치·회복/복귀 시간·반복 간격은 플레이 테스트로 튜닝한다. 간파 슬로우모션 여부는 기존 D18 미확정 상태를 유지한다.
- 이 교육용 반응과 상태 전환은 튜토리얼 스피너봇에만 적용하고 일반 몬스터·다른 스테이지의 정상 취약 규칙에는 영향을 주지 않는다.

### 3.6 복도3 — 특성 선택(설명 없음)

- 제한시간: 솔로 첫 플레이 추정 = 처치량 약 9,000HP(모서리 4무리 + 알람 2무리 + 2층 한쪽 + 중간보스 3,600) ÷ DPS 45~60 ≈ 150~200초 + 이동 약 35초 + 패널·다리·회피 → **250~330초**. 여기에 복도4 특성 선택(약 10~20초)도 타이머 안에 들어간다. 그래서 **420초**(D6 확정). 플레이테스트에서 너무 길거나 짧으면 그때 조정한다.

## 6. 특성(복도 선택) — 구현 제약 메모

> 🔴 **특성이 무엇인지(이름·풀·제시 장 수·무작위 여부·효과·중복 규칙·획득 표시)는 별도 "특성 기획서"가 원본이다**(D8 확정 — 공유 예정). 이 문서는 **튜토리얼에서 언제·어디서 고르는지**만 정한다. 아래는 특성 기획서를 구현할 때 부딪힐 **현재 코드 제약** 메모다.

- 특성 선택 시스템은 **코드에 없다**(특성·보상 선택·상점·BuildModifier 클래스 0). 문서상으로도 "로비에서 고르는 빌드/시그니처 특성"과 8월+ 초안의 "런 중 상점"만 있다. 복도 선택은 새 기능이다.
- 튜토리얼이 요구하는 최소 흐름: **복도 4곳**에서 각각 **카드 N장 중 1장**(개인 선택) → 서버 확인 → 효과 적용 → 획득 표시. 한 판에 특성 **4개**를 얻는다.
- 4번 고르므로 특성 기획서에 **중복 획득 규칙**(중첩 / 후보 제외)이 있어야 한다. 지금 스탯 배율은 (종류, 출처 id) 가 같으면 덮어써지므로, 중첩시키려면 특성마다 출처 id 를 달리해야 곱해진다.
- 지금 실효 배율이 2종뿐이라, 특성 기획서의 효과가 스탯 위주면 배선 작업(아래)이 먼저 필요하다.
- **지금 그대로 효과가 나는 스탯 배율은 공격력·이동 속도 2종뿐**이다.
  - 공격 속도·방어 배율은 값만 있고 **읽는 곳이 없다**(평타 속도·피해 경감이 기본값을 직접 씀).
  - 최대 체력 배율은 **HP 바 분모에만** 들어간다. 실제 체력 상한·회복·부활은 기본값이라, 고르면 체력은 그대로인데 바가 약 83% 로 보인다.
  - 세 가지를 쓰려면 배선 작업이 따로 필요하다(§7.2).
- 배율은 **1 이상만** 쓴다(1 미만은 디버프로 분류돼 보스방 진입 연출 때 지워진다). 사망·부활로는 지워지지 않는다.
- 비율 쿨감(예: 쿨 −10%)은 스킬 쿨 시작값을 SO 에서 직접 읽어 지금은 불가. "적중 시 Q 쿨 n초 감소" 같은 **이벤트형 쿨 감소**는 기존 서버 API(`ReduceCooldownServer`)로 가능하다.
- 획득한 특성을 **어디서 다시 보는지**가 필요하다(지금은 상태이상 HUD 에 `AttackDamage` 같은 내부 이름으로만 뜬다).

### 7.2 v5 당시 개발 항목 기록 + 최신 변경 인계
> 아래 1~15는 v5 당시의 목록이며 사용자가 개발 완료했다고 전달했다. 이번 변경 범위는 아래 **v7 변경 인계**를 우선한다.
1. **튜토리얼 진행 상태**(서버 소유, 복제) — 단계·개인 체크리스트·게이트 상태. 존 프리팹은 비네트워크라 씬 상주 객체가 필요.
2. **구간 진입 감지**(존1~4, 복도1~4 중간) — 기존 벽 투명화 트리거는 클라 로컬 연출용이고 옆 존까지 덮어서 그대로 못 쓴다.
3. **개인 체크리스트 판정** — 이동 거리(오너 권한이라 오너 → 서버 보고 등 필요) · 대시(서버 승인 지점) · 패시브 툴팁 "표시됨"(지금 `visible` 이 private, 클라 로컬 → 서버 보고) · 스킬 "사용"(Q·E — E 계열은 적중 이벤트가 안 난다) · 간파 성공/빗나감.
4. **배리어**(G1~G4·G6·G7·G9·G10) — 모든 피어에서 막힘(이동이 오너 권한), 몬스터도 막힘(NavMesh), 대시 통과 불가, 개방 상태 복제·늦은 클라 재적용. 공용 존 프리팹이 아니라 튜토리얼 쪽에 둘 것. 추락 복구 후보가 배리어 너머로 잡히지 않게.
5. **몬스터 휴면/기상**(존 단위 + 중간보스 개별) — 휴면 = 인지·공격 안 함 + 무적.
6. **존 클리어 판정**(존2 전멸, 존3 스피너봇, 존4 중간보스) — 몬스터를 존별로 묶는 장부가 없다.
7. **타이머 지연 시작** — 자동 시작 끄기 + 서버 시작 API + Idle 때 HUD 숨김. 만료 유지·도착 정지·영혼 강제 부활 계약은 지킬 것(경석 영역). **Stage1 이 모든 판이라 본게임에도 적용됨**(D1).
8. **보스방 길 잠금**(D3 확정) — 복도4 입구 배리어(중간보스 처치 시 개방) + 복도4 출구 배리어·보스 진입 패드 비활성(복도4 특성 전원 선택 시 개방). 타이머 만료 강제 이동은 막지 말 것. Stage1 이 모든 판이므로 튜토리얼 스테이지에만 적용되게.
9. **튜토리얼 사망 규칙**(§2.5) — 자동 부활(단계 기준 목숨 차감 여부), 부활 지점·무적, 이동 중 대기 부활 취소, 연출 잠금 중 처리.
10. **존1 평타 허수아비**(간파 사이클 없는 변형) — 허수아비 프리팹 수정은 Debug 연습장에도 영향 → 변형으로.
15. **스피너봇 연계 교육 → 본 모드**(§3.5) — 간파 → 취약 밀치기 → 벽 충돌 연계를 파티 합계 3회 성공하고 마지막 원위치 복귀가 끝나면 본 모드. 튜토리얼 대상에만 적용한다.
11. **안내 UI**(목표 패널·자막·강조) — 사망·관전 중에도 보이게, 늦은 클라 재구성.
12. **특성 선택**(§6) — 복도 4곳 · 데이터·카드 UI·선택 RPC·서버 검증(제시된 후보인지, 이미 골랐는지)·획득 표시·자동 획득(교착 방지·타이머 만료) · **선택 창이 열린 동안 무적** · 중복 획득 규칙.
13. 공격 속도·방어·최대 체력 배율 배선(이 특성들을 쓸 경우 — 획득 순간 현재 체력 처리 포함).
14. 엘리베이터 문 열림 구동(애니메이터에 파라미터·전이 없음).

#### v7 변경 인계 (존1·복도1·존2는 v6 변경 유지)
1. 존1 실제 사용 5종을 개인별로 집계하고 G1 조건에 모두 포함. 단순 키 입력·적중 이벤트만으로 판정하지 않음. 거너 Q 발사와 R 대상 확정, 어쌔신 R 변신 진입을 구분.
2. 복도1 입구 첫 진입을 플레이어별로 기록하고, Q·E·R·우클릭·대시 및 별도 일반/변신 쿨타임을 초기화. 진행 중 행동 종료 후 쿨타임이 생기는 경우도 검토.
3. 존2 Q·E 체크와 미사용 경고 제거. 전멸 판정은 유지.
4. 존3을 준비·간파 → 취약 유지·밀치기 → 벽 충돌 성공 → 원위치 복귀의 연계 루프로 변경. 우클릭 밀치기 원인의 유효 벽 충돌만 1회 집계하며 동시·중복 이벤트는 차단.
5. 간파 성공마다 파티 우클릭 쿨타임을 1회 초기화. 벽 충돌 전 취약 유지와 자율 이동·공격 정지, 복귀 중 피해·밀치기 무시·추격 중지·몸 충돌 교착 방지 적용. 성공 3회와 마지막 복귀 완료를 G5 조건으로 사용. 이후 교육용 규칙을 모두 해제.
6. 변경 안내 ID·목표 패널·QA 갱신. 이 문서는 구현 완료 보고가 아니라 변경 요청이다.
7. **v8 문구 정리**: `TUT_Z2_Q_*`·`TUT_Z2_E_*`·`TUT_Z3_GUNNER` 호출·예약 자막·슬롯 강조를 제거한다. 이미 등록된 문구 데이터가 남아 있어도 존2·존3에서 호출하지 않는다. 존1 스킬 사용 힌트와 존3 공통 연계 안내는 유지한다.

## 9. 완료 기준 (QA 체크리스트)

- [ ] 솔로 × 3캐릭터: 존1 → 보스방 도착까지 막힘 없이 진행, 각 단계 문구가 캐릭터에 맞게 나온다(어쌔신은 분노 게이지 기준).
- [ ] 존1: 기본 공격·Q·E·R·우클릭 5종 중 하나라도 미사용이면 G1이 열리지 않음. 각 1회 사용과 기존 조작 체크 완료 후 개방. 적중 실패는 사용으로 인정하지만, 조준 취소·입력 거부는 미인정.
- [ ] 존1: 거너 Q 충전 시작만으로 완료되지 않음. R 대상 확정용 좌클릭이 기본 공격으로 중복 집계되지 않음. 어쌔신은 허수아비에서 분노를 모아 R 사용 가능.
- [ ] 복도1: 플레이어별 첫 진입 시 Q·E·R·우클릭·대시 쿨타임 0. 일반/변신 별도 쿨도 초기화. 왕복·부활 재진입 시 재초기화 없음. 진행 중 행동 종료 후 다시 생기는 쿨타임도 검토.
- [ ] 존2: 스킬 사용 여부와 관계없이 몬스터 9마리 전멸만으로 G3 개방. Q·E 사용 체크·미사용 경고 없음.
- [ ] 존2·존3: 캐릭터별 Q·E 상세 설명과 거너 간파/후폭풍 설명이 나오지 않음. 이전 단계에서 예약된 자막도 재생되지 않음. 처치·간파·밀치기·벽 충돌 공통 안내는 정상 출력.
- [ ] 존1~3 에서 길을 건너뛸 수 없다(배리어 — 걷기·대시·추락 복구 모두). 존4 에서 중간보스 전에 복도4 로, 복도4 특성 전원 선택 전에 패드로 갈 수 없다(D3) — 그래도 타이머 만료 강제 이동은 정상.
- [ ] 휴면 몬스터는 배리어 너머 원거리 공격(거너 평타·Q·R, 팔라딘 R)에 피해·넉백을 받지 않는다. 다리 개통 전 중간보스를 원거리로 잡을 수 없다.
- [ ] 복도1~4 특성 선택이 각 1번씩 뜨고(설명은 복도1 만), 선택 창이 열린 동안 피해를 받지 않는다. 특성 4개가 실제 수치에 반영되고(중복 규칙대로) 보스전까지 유지된다.
- [ ] 복도4: 고르는 동안 타이머가 계속 찬다. 고르는 도중 타이머가 다 차면 창이 닫히고 무작위 1장 획득 후 강제 이동된다.
- [ ] 존3: 간파 → 취약 우클릭 밀치기 → 유효 벽 충돌의 연계만 1회 집계. 간파만 3번 하거나 벽에 닿지 않는 밀치기만으로는 본 전투가 시작되지 않음.
- [ ] 존3: 벽 충돌 전까지 취약이 시간으로 끝나지 않음. 중간보스가 자율 이동·추격·공격하지 않지만 우클릭 밀치기에 의한 이동은 가능. 교육 중 죽지 않음.
- [ ] 존3: 간파 성공마다 파티 우클릭 쿨을 1회 초기화. 밀치기 빗나감·벽 미도달 시 취약과 기존 연계 횟수 유지, 정상 쿨타임 후 재시도 가능.
- [ ] 존3: Q 넉백·자기 돌진·복귀 이동·기존 벽 접촉·상자/플레이어/배리어 충돌은 연계 성공으로 세지 않음. 동시 밀치기와 충돌 중복 이벤트도 해당 연계 1회만 집계.
- [ ] 존3: 각 벽 충돌 성공 후 취약 종료·원위치 복귀. 복귀 중 피해·외부 밀치기·추격 없음. 플레이어가 복귀 경로를 막아도 교육이 멈추지 않음. 배리어를 넘지 않음.
- [ ] 존3: 성공 3회 후 마지막 복귀를 마치고 본 전투. 교육용 정지·취약 유지·무적·쿨 초기화 해제, 정상 체력·패턴·취약 시간 적용. 이후 처치해야 복도3 개방.
- [ ] 존3 멀티: 간파한 사람과 밀친 사람이 달라도 같은 사람이어도 인정. 파티 합계 3회, 개인별 성공 강제 없음. 죽거나 이탈해도 기존 성공 횟수 보존. 솔로도 같은 흐름으로 완료 가능.
- [ ] 타이머는 존4 진입 + 설정 자막 뒤에 처음 차오른다. 존1~3 에서 아무리 오래 있어도 강제 이동이 없고, HUD 틀도 안 보인다.

- [ ] 사망: 보스방 도착(G11) 전에는 타이머 시작 뒤에도 목숨 그대로 부활, 도착 뒤에는 일반 규칙(목숨 차감). 부활 대기 중 패드·강제 이동이 일어나도 옛 구간으로 끌려가지 않는다.
