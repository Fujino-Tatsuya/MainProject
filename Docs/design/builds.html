빌드 (Build = 모디파이어 픽)

7월 스코프엔 인게임 성장(레벨/XP) 없음. 로비에서 빌드(모디파이어)를 골라 입장하면 그게 곧 시작 로드아웃.

레벨 시스템은 골격만 두고 비활성. 8월 맵/레벨 디자인과 함께 콘텐츠 연결.

개념

  • 로비에서 모디파이어 N개(예시: 5종) 를 선택해 입장. 보스전만 진행.
  • 모디파이어 = "스탯/스킬을 가/감하거나 동작을 바꾸는 효과 1종".

모디파이어 풀 (예시 — 구체안은 회의 후 확정)

  • 공격력 상수 + 약간
  • 방어력 +
  • 특정 스킬 데미지 추가
  • 특정 스킬이 데미지를 2회 주는 것으로 변경
  • 궁극기(R) 해금
  • 랜덤/특정 스킬 쿨타임 감소
  • (기타 — 회의에서 확정)

R 잠금/해금

  • R 스킬은 기본 잠금 상태로 노출(시작 시 잠금 UI도 보여줄 수 있음).
  • "궁극기 해금" 모디파이어를 빌드에 넣어야 R 사용 가능. 이건 예시임.
  • 8월+(레벨 도입 시): R 해금 본체 = 런 내 레벨 도달, 이 모디파이어는 "해금 가속"(레벨↓/즉시)으로 재정의. level-system.md §1.

시스템 요구 (데이터 주도)

  • BuildModifier = ScriptableObject 로 효과 1종 표현.
  • 스폰 시 서버에서 선택 빌드를 적용:
    • 스탯 가산 → 스탯 모디파이어 레이어
    • 스킬 데미지 추가/2회타격/해금/쿨감 → AbilityConfig 런타임 패치
  • 무엇이 확정되든 끼울 수 있게 시스템은 열어둔다(픽 개수/풀/캐릭터별 분리/중복 규칙은 미정).

미정 (회의)

  • 픽 개수, 풀 구성, 캐릭터별 분리 여부, 중복 선택 규칙.
