## 0. 핵심 원칙 — "레벨" 4축 분리

"레벨"이라 부르는 게 4개라 코드/밸런싱에서 절대 섞지 않는다. **플레이어 성장(내가 세짐) ↔ 콘텐츠 난이도(적이 세짐)** 는 완전 독립.

| 축 | 범위 | 역할 | 위치 |
|----|------|------|------|
| ① 런 내 레벨 | 한 런(리셋) | 스탯 소폭↑ + 일정 레벨 궁극기(R) 해금 | §1 |
| ② 캐릭터 고유 레벨 | 영구 | 룬 장착 칸 ↑ | §2 |
| ③ 룬 강화 | 영구 | 공용=캐릭터 공유 / 고유=비공유 | §2 |
| ④ **콘텐츠 난이도** | 런/콘텐츠 | 적·밀도·보상 스케일 | §3 ★지금 작업 |

## 1. 런 내 성장 (In-Run, 매 런 리셋)

- **런 내 레벨:** 처치/진행으로 레벨업 → 전체 스탯 소폭 상승, **일정 레벨 이상 궁극기(R) 해금(기본 경로).**
  - ✅ **R 해금 = 레벨 도달이 본체.** [builds.md](builds.md)의 R해금 모디파이어는 **"해금 레벨↓ / 즉시 해금" 가속 옵션**으로 재정의(중복 해소, 2026-06-15). 7월 슬라이스(레벨 없음)는 모디파이어 해금 그대로.
- **상점:** 아이템(특수효과)·패시브 추가·`Q/E/R`·좌클릭(평타)·우클릭(고유) 강화 또는 스킬 변경.
- **빌드(모디파이어):** 입장 시 픽( [builds.md](builds.md) ). 런 내 시작 로드아웃.
- **콤보:** 런 내 지속 전투 보상. **플레이어 개인 단위**, 씬 전환/사망 시 리셋(콤보 상세 §6). → §4.

## 2. 메타 성장 (Between-Run, 영구)

- **빌드 해금:** 런 종료 후 신규 빌드/모디파이어 해금.
- **캐릭터 고유 레벨:** 해당 캐릭터 플레이 종료 시 **고유 경험치** 획득 → 레벨업 → **룬 장착 칸 증가**.
  - 예시 곡선: Lv1 = 고유 0 / 공용 3칸 → Lv50 = 고유 3 / 공용 30칸. (실곡선 §5 TBD)
- **룬(전부 보유, 재화로 강화):**

  | 종류 | 강화 공유 | 기능 |
  |------|-----------|------|
  | 공용 룬 | **캐릭터 간 공유** (한 번 강화하면 다른 캐릭터도 강화본 사용) | 범용 스탯/효과 |
  | 고유 룬 | **비공유** (캐릭터별 개별 강화) | 스킬 변경·스킬 강화·로직 변경·특수 스킬 등 |

- **재화:** 캐릭터 고유 경험치 + 공용 재화. 룬 강화·고유 레벨에 사용.

## 3. 콘텐츠 난이도 레벨 ★ (지금 작업 — 데이터층 §map-generation §5.2)

플레이어 성장과 **완전 분리**. 난이도는 "적이 세지거나 환경이 가혹해지거나 적이 많아지는" 축.

**런 구조(확정):** 여러 스테이지 순차(Stage1→2→3→4, **현재 Stage1만**) + **사전 난이도 선택**. 상승 난이도(Heat/승천) 채택 — "사전 선택"과 "상승 난이도"는 **하나의 축(Ascension)** 으로 통합.

**스케일 방식 = (Size, Difficulty) 디자인 세트 선택** (v2 — [map-generation §5](../tech/map-generation.md)). 난이도가 수치를 직접 곱하지 않고 **그 난이도용으로 디자인된 존 세트**를 고른다 — 더 많은/센 몬스터·구성이 디자인에 이미 박혀 있음. (`DifficultyTableSO` 카운트 스케일·장애물 **폐기**, 몬스터 디자인 내장)

| 무엇이 난이도로 갈리나 | v2 실현 |
|------|------|
| 양(몹 수)·구성 | 난이도별 **디자인 변형**에 내장(기획이 디자인) |
| 질(HP/인터럽트창/Break) | 몬스터 그룹·스탯에 내장 또는 런타임 배수(몹 작업 시) — §4 |
| 보상 | 배수(메타성장 §2 연결) — TBD |

**현재 상태:** `Generate(seed, int level)` + `DifficultyLevel`(서버 `MapNetworkSync`의 NetworkVariable로 합성) + `ZoneLayoutCatalog`의 (Size×Difficulty) 풀 선택까지 **코드 완료**. 초기엔 단일 난이도(Difficulty=0) 세트로 시작.

## 4. 난이도 ↔ 전투 시스템 상호작용 (전투 4문서 종합)

난이도(③ 질 축)와 플레이어 성장이 각 전투 시스템의 **어떤 데이터 필드**를 건드리는지. 이게 "고난이도다움"을 만든다 (단순 HP×배수 금지).

> **조작/슬롯(2026-06-15 결정):** 우클릭은 [ability.md](ability.md)의 `SecondaryAction` 기본 입력이다. 캐릭터에 따라 인터럽트, 방어, 특수 공격, 스택 발동 등으로 해석될 수 있다. 가붕이 **패링**·징크스 **스택 발동**은 캐릭터별 `SecondaryAction` 후보로 유지한다.
> - 가붕이(패링·방어형): 정면 인터럽트 가능 특수를 **패링 성공** 시 인터럽트 판정.
> - 징크스(스택·공격형): 스택 보유 몬스터에 **스택 발동** 적중 시 인터럽트 판정.

| 전투 시스템 | 난이도↑ 가 미는 것 | 플레이어 성장이 미는 것 | 데이터 필드(출처) |
|-------------|--------------------|--------------------------|--------------------|
| **인터럽트** | 인터럽트 가능 창(`InterruptTimeStart~End`) 축소, 인터럽트 불가 특수 비율↑ | 룬/빌드로 창 보정·인터럽트 강화 | `MonsterPatternData{IsInterruptable, InterruptTimeStart, InterruptTimeEnd}`, `SkillData{HasInterrupt}` |
| **그로기/브레이크** | `GroggyDuration`/`BreakDuration`↓, `BreakRequireCount`↑ (몬스터 등급·보스별) | **Groggy Count 증가량 >1** (캐릭터/빌드, 연계 §5) | `MonsterStateData{GroggyCount, BreakRequireCount, GroggyDuration, BreakDuration}` |
| **콤보** | (직접 결합 약함 — 개인 보상) 단 **씬 전환마다 리셋** → 스테이지 진행 페이싱에 영향 | `ComboMaintainTime`·보정 곡선 강화 | `ComboMaintainTime`, 보정 밴드(0–50/51–100/101–150/151+) |
| **연계** | Groggy/Break 창이 짧아지면 **연계 윈도우도 짧아짐**(간접) | Groggy Count 증가량↑로 브레이크 가속 | 최대 3연계, 참여 1회 제한 |

> **그로기/브레이크는 데이터로 아키타입 게이팅**(잡몹=없음, 엘리트 `BreakRequireCount`小, 보스 풀가동). 등급/난이도별 지속시간은 전투 기획서가 명시한 설계와 일치.

## 7. 시스템 핵심 요약 (Summary)

### 개요 및 스코프
- **7월 수직 슬라이스:** 인게임 레벨/XP 시스템 없음 (골격만 유지)
- **8월 이후:** 본 문서 기반으로 레벨/난이도 콘텐츠 연결 구체화

### 레벨 4축 분리
- **런 내 레벨 (매 런 리셋):** 레벨업 시 스탯 소폭 상승 및 궁극기(R) 해금
- **캐릭터 고유 레벨 (영구):** 캐릭터 플레이 경험치로 레벨업 → 룬 장착 칸 증가
- **룬 강화 (영구):** 공용 룬(공유) 및 고유 룬(비공유, 스킬 및 로직 변경) 강화
- **콘텐츠 난이도 (런/콘텐츠):** 사전 난이도 선택 + 승천(Ascension) 통합. 몹 수, 구성, 전투 압박, 보상 연동

### 전투 시스템 상호작용
- **우클릭:** 캐릭터별 고유 인터럽트 스킬 (패링, 스택 등 성공 시 판정)
- **난이도 상승 영향:** 단순 HP/DMG 상승을 넘어 인터럽트 가능 시간 축소, 그로기/브레이크 지속시간 단축 및 요구량 증가 등으로 플레이어를 압박
