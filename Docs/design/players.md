# 플레이어 캐릭터

> 7월 스코프: **근거리(가붕이) / 원거리(징크스) 1종씩**. 스킬은 러프하게 구현, 쿨타임 등 수치는 참조 기준에 맞춰 튜닝.
> `Q/E/R` 옆 코드네임은 **팀 내부 참조용**이며, 실제 동작·수치는 구현 시 팀이 확정한다.

## 공통
- **좌클릭 = 평타(기본 공격).** 두 캐릭터 공통. (보스의 폭탄도 이 평타로만 상호작용 — [boss 문서](boss-wells-and-no23.md) §폭탄)
- **우클릭 = 캐릭터별 고유 액션** (근거리 = 패링 / 원거리 = 스택 발동).
- **대쉬 시 무적** (무적 윈도우 동안 피격 무효 — 서버가 판정).

## 상태이상 (피격 시 받을 수 있음)
- 공중에 뜸 / 기절 / 둔화 / 속박 / 침묵(스킬 봉인) / 허약(= 대쉬 불가 + 둔화)
- 정의·게이팅 규칙: [status-effects.md](status-effects.md)

## 가붕이 — 한손검, 방패 (근거리)
| 슬롯 | 내용 | 비고 |
|------|------|------|
| 좌클릭 | 평타(기본 공격) | 근접 타격 |
| 우클릭 | **패링** | 바라보는 방향으로 오는 공격만 막음. 쿨 3~5초(작게) |
| Q | 크산테w (참조) | 동작·수치 TBD |
| E | 가붕이w (참조) | 동작·수치 TBD |
| R | 가붕이r (참조) | **기본 잠금**, 빌드로 해금 |

- **패링**: 방패 기반, **정면(바라보는 방향)으로 들어오는 공격만 막는다**(방향 판정). 성공 시 해당 피격 무효(후속 효과 TBD).
  쿨타임 3~5초로 짧게. 판정은 서버 권한.

## 징크스 — 대포 (원거리)
| 슬롯 | 내용 | 비고 |
|------|------|------|
| 좌클릭 | 평타(기본 공격) | **적중 시 그 몬스터에 스택 누적**(트위치류) |
| 우클릭 | **스택 발동** | 주변 범위 내 **스택 쌓인 몬스터가 있을 때만 사용 가능**. 쿨 3초 |
| Q | 징크스e (참조) | 동작·수치 TBD |
| E | 애쉬w (참조) | 동작·수치 TBD |
| R | 징크스r (참조) | **기본 잠금**, 빌드로 해금 |

- **스택 메커니즘**: 좌클릭 평타가 대상 몬스터에 **스택을 쌓고**, 우클릭은 **주변 범위 내 스택 보유 몬스터가 있으면**
  활성화되어 스택을 소비/발동(쿨 3초). 스택 수치는 **적(UnitBase)이 보유**(서버 권한, 클라 복제).

## 구현 참고
- **R는 기본 잠금** 상태로 노출되고, 빌드(모디파이어) 선택으로 해금. ([builds.md](builds.md))
- 입력은 **Unity Input System(액션 에셋)**: 좌클릭(평타)/우클릭(고유)/Q/E/R/이동/대쉬 액션 정의.
  발동/판정은 클라(오너)가 트리거, **데미지/CC/패링 방향판정/스택은 서버 RPC**.
- 각 스킬은 `AbilityConfig`(ScriptableObject)로 데이터화 → 빌드가 런타임 패치(데미지 추가/2회타격/쿨감 등).
- **쿨타임·범위·스택 수 등 수치는 `[SerializeField]`로 노출**해 직렬화로 빼두고, 실제 플레이하며 튜닝.
