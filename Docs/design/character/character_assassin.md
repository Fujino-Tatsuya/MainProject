## 1. 문서 목적과 적용 범위

암살자 캐릭터의 일반·변신 상태별 공격, R 스택, 입력 처리와 상태 종료 규칙을 정의함. 기본 공격·Q·E·R·우클릭 간파를 다루며, 공통 이동·대시·간파 시스템은 기존 캐릭터의 구현을 사용함.

정확한 타격 시점과 행동 종료 시점은 애니메이션 적용 단계에서 조정함. 본 문서에서 새 수치가 확정되지 않은 공통 동작에 임의의 성능이나 취소 규칙을 추가하지 않음.

## 2. 전체 구조

1. 일반 상태에서 Q로 이동하고 기본 공격을 사용함.
2. 일반 E를 사용하면 다음 기본 공격이 별도의 강타로 변경됨.
3. 강타가 보스·일반 몬스터·송전기에 적중하면 R 스택 1개를 획득함.
4. 최소 1스택과 사용 가능한 R이 있으면 보유 스택을 전부 소모하여 변신함.
5. 변신 중 기본 공격·Q·E가 변경되며 R 스택을 획득할 수 없음.
6. 변신 종료 후 일반 상태로 복귀하고 R 쿨타임을 시작함.

| 구분 | 일반 상태 | 변신 상태 |
|---|---|---|
| 기본 공격 | 1~4타를 순서대로 사용 | 입력 1회로 4타 묶음 사용 |
| Q | 고정 거리 관통 돌진 | 같은 성능의 돌진, 짧은 쿨타임과 적중 쿨타임 감소 |
| E | 다음 기본 공격을 강타로 변경 | 고정 원형 범위에 동일 피해 5타 |
| R | 스택 전부 소모하여 변신 | 시작 후 2초가 지나면 재입력으로 해제 가능 |
| 우클릭 | 공통 간파 | 일반 상태와 동일한 공통 간파 |
| 백어택 | 보스 후방 120도에서 적중 시 적용 | 적 대상의 모든 타격에 자동 적용 |

## 3. 공통 입력과 공격 규칙

### 3.1 스킬 예약 없음

- 공격이나 스킬 동작 중 사용할 수 없는 Q·E·간파·R 입력은 무시함.
- 무시된 입력을 저장하거나 동작 종료 후 자동 실행하지 않음.
- 해당 동작 종료 후 사용하려는 버튼을 다시 입력해야 함.
- 일반 기본 공격에서 다음 타를 미리 예약하는 클릭 입력도 사용하지 않음.
- 좌클릭을 계속 누르는 입력은 예약이 아니라 동작 종료 시 현재 입력 상태를 확인하는 방식임.
- 변신 중 R 수동 해제와 시간 만료에 따른 종료 대기는 예외적으로 변신 종료 요청을 유지함. 다른 스킬을 나중에 실행하는 입력 예약과 구분함.

### 3.2 입력과 상태

- 일반 기본 공격·강타·변신 기본 공격 도중 Q·E·R 신규 시전은 불가함. 변신 R의 수동 해제는 별도 종료 규칙을 따름.
- 일반 E의 Buff 동작 중 기본 공격·Q·R·간파를 사용할 수 없음.
- R의 Parry_R 동작 중 이동·대시·기본 공격·다른 스킬을 사용할 수 없음.
- 변신 E 공격 중 이동·대시·다른 스킬을 사용할 수 없음. R 해제를 입력하면 공격 완료 후 종료함.
- 나머지 동작의 이동·대시 취소와 간파 중 행동 제한은 기존 캐릭터의 공통 구현을 따름.
- 쓰러짐·사망 상태에서는 새로운 공격과 스킬을 시작할 수 없음.

### 3.3 피해와 다단히트

- 피해 계수는 공격력을 기준으로 계산함. 방어력과 공통 피해 계산 순서는 기존 전투 시스템을 따름.
- 한 타격이 같은 대상을 여러 번 중복 감지해도 해당 타격의 피해는 1회만 적용함.
- 다단히트는 다음 타격에서 같은 대상에게 다시 피해를 줄 수 있음.
- 타격마다 현재 범위 안의 대상을 판정함. 처음 맞은 대상을 이후 타격에 자동으로 포함하지 않음.
- 모든 피해·거리·속도·쿨타임·재생 속도는 본 문서의 임시값으로 테스트 후 조정 가능함.

## 4. 패시브 — 백어택과 R 스택

### 4.1 백어택

- 보스 후방 중심에서 좌우 60도, 총 120도를 백어택 범위로 사용함. 범위는 보스 측 공통 판정을 사용함.
- 각 타격의 적중 시점에 보스 방향과 플레이어 위치로 판정함.
- 백어택인 타격의 피해에 1.2배를 적용함. 피해 증가량 20%는 임시값임.
- 같은 다단히트 공격 안에서도 타격별 백어택 여부가 달라질 수 있음.
- 현재 일반 몬스터에는 위치에 따른 백어택 판정을 사용하지 않음.
- 변신 중에는 보스·일반 몬스터를 공격하는 모든 타격을 위치와 관계없이 백어택으로 처리함.
- 송전기 등 기믹용 오브젝트에는 변신 중에도 백어택 효과를 적용하지 않음.
- 박스 등 일반 파괴 오브젝트에는 백어택 증가를 적용하지 않음.

### 4.2 R 스택

- 최대 4개까지 보유함. 최대치를 넘는 획득은 추가하지 않음.
- 일반 E로 강화한 강타가 유효 대상에 적중하면 1개 획득함.
- 강타 1회로 여러 유효 대상을 맞혀도 스택은 1개만 획득함.
- 일반 기본 공격과 Q는 스택을 생성하지 않음.
- 변신 중에는 어떤 공격으로도 R 스택을 획득하지 못함.
- R을 시전하면 보유 스택을 전부 소모하고, 쓰러짐·사망 시 스택을 0으로 초기화함.

### 4.3 적중 보상 대상

| 대상 | 일반 E 강타의 스택 획득 | 변신 Q 쿨타임 감소 | 백어택 효과 |
|---|---|---|---|
| 보스 | 적용 | 적용 | 일반: 후방 조건 / 변신: 자동 적용 |
| 일반 몬스터 | 적용 | 적용 | 일반: 없음 / 변신: 자동 적용 |
| 송전기 | 적용 | 적용 | 모든 상태에서 없음 |
| 박스 등 일반 파괴 오브젝트 | 적용하지 않음 | 적용하지 않음 | 없음 |

송전기를 제외한 다른 기믹용 오브젝트의 적중 보상 여부는 해당 기믹에서 별도로 지정함. 기믹용이라는 이유만으로 모든 오브젝트에 스택·쿨타임 감소를 자동 적용하지 않음. 백어택 제외 규칙은 기믹용 오브젝트 전체에 적용함.

## 5. 일반 기본 공격

### 5.1 실행과 연결

- Combo_Attack_Wave_01~04를 1~4타로 순서대로 사용함.
- 좌클릭 유지 시 1 → 2 → 3 → 4 → 1 순서로 반복함.
- 클릭 1회는 현재 순서의 1타만 실행함. 동작 중 추가 클릭으로 다음 타를 예약하지 않음.
- 버튼을 놓아도 현재 타의 동작은 완료하며 다음 타는 실행하지 않음.
- 공격 중 이동할 수 없음. 대시 취소는 공통 구현 기준을 따름.
- 각 타 시작 시 마우스 방향을 저장하고 해당 타가 끝날 때까지 유지함.
- 전방 부채꼴을 사용하고 베는 순간에 피해를 1회 적용함.
- 각 타 종료 후 0.8초 이내에 다시 공격하면 다음 타부터 사용함. 초과하면 1타로 초기화함.
- Q·E·R로 전환하면 일반 공격 순서를 초기화함.
- E 강타는 일반 4타 순서와 별도이며, 강타 종료 후 일반 공격 1타부터 시작함.

### 5.2 임시 수치

| 항목 | 1타 | 2타 | 3타 | 4타 |
|---|---|---|---|---|
| 피해 계수 | ×1.0 | ×1.0 | ×1.0 | ×1.3 |
| 전방 사거리 | 1.5m | 1.5m | 1.6m | 1.7m |
| 부채꼴 각도 | 90도 | 100도 | 100도 | 120도 |
| 재생 속도 | 3배 | 3배 | 3배 | 2.5배 |
| 예상 클립 길이 | 약 0.42초 | 약 0.42초 | 약 0.42초 | 약 0.5초 |

총피해 계수 ×4.3, 전체 클립 재생시간 약 1.75초임. 범위 기준은 캐릭터 중심임. 예상 시간은 원본 클립 약 1.25초를 재생 속도로 나눈 값이며, 실제 판정 시간이나 취소 가능 시점을 확정한 값이 아님.

## 6. 변신 기본 공격

- Speed_Attack_Loop 한 번에 4타가 포함된 공격 묶음을 사용함.
- 입력 1회당 4타 묶음을 실행하고 좌클릭 유지 시 묶음을 반복함.
- 버튼을 놓아도 시작한 묶음은 끝까지 실행함.
- 4타 각각 같은 피해량과 범위를 사용함.
- 공격 중 Q·E로 전환할 수 없고 입력을 예약하지 않음. 묶음 종료 후 재입력해야 함.
- 변신 시간이 끝나거나 유효한 R 해제 요청이 있으면 현재 묶음을 완료하고 변신을 종료함. 다음 묶음은 시작하지 않음.

| 항목 | 임시값 |
|---|---|
| 타격당 피해 | 공격력 ×1.2 |
| 4타 총피해 | 공격력 ×4.8 |
| 백어택 적용 총피해 | 공격력 ×5.76 |
| 전방 사거리 / 각도 | 1.8m / 120도 |
| 재생 속도 / 묶음 시간 | 1.25배 / 약 0.53초 |

기믹용 오브젝트에는 백어택 배율을 제외함. 변신 기본 공격 중 이동·대시 처리는 기존 공통 구현을 확인하여 적용함.

## 7. Q — 일반·변신 관통 돌진

### 7.1 공통 규칙

- Q 입력이 받아들여진 시점의 마우스 방향으로 고정 거리 돌진함. 도중 방향을 변경하지 않음.
- 일반 몬스터와 보스를 통과함.
- 벽과 통과 불가능한 지형에 닿기 직전에 돌진을 종료함.
- 이동 경로를 따라 피해를 적용하며 종료 지점에서만 판정하지 않음.
- 같은 대상에게 Q 사용 1회당 최대 1회 피해를 적용함.
- 돌진 중 저지불가를 적용함. 무적은 없으며 피해를 받음. 저지불가의 상세 상태 이상 대응은 공통 규칙을 따름.
- 실제 이동은 스킬 이동 로직으로 처리하며 애니메이션 루트 이동을 중복 적용하지 않음.
- 벽으로 조기 종료해도 쿨타임과 피해 계수는 변경하지 않음.
- 돌진을 실제로 시작하지 못했다면 쿨타임을 시작하지 않음.
- 일반 E 강화는 Q로 발동·소모되지 않음. Q로 R 스택을 획득하지 않음.
- 일반·변신 Q의 이동 성능과 피해 계수는 같음. 애니메이션과 쿨타임 규칙만 다름.

### 7.2 임시 수치

| 항목 | 일반 Q | 변신 Q |
|---|---|---|
| 피해 계수 | ×1.5 | ×1.5 |
| 돌진 거리 | 4m | 4m |
| 돌진 속도 / 이동시간 | 20m/s / 약 0.2초 | 동일 |
| 공격 폭 | 1.2m | 1.2m |
| 쿨타임 | 5초 | 3초 |
| 쿨타임 시작 | 돌진 시작 | 돌진 시작 |
| 적중 보상 | 없음 | 기본 쿨타임의 50%인 1.5초 차감 |
| 애니메이션 | Combo_Attack_02_04 | Combo_Attack_03_04 |

### 7.3 변신 Q 쿨타임 감소

- 각 Q 사용의 최초 유효 적중에서 1회 적용함.
- 여러 적·송전기를 맞혀도 총 1.5초만 차감함. 다음 Q 사용에서도 적중하면 다시 적용함.
- 남은 쿨타임을 절반으로 만드는 것이 아니라 기본 쿨타임의 절반만큼 차감함.
- 예: 남은 2.8초에 적중하면 1.3초로 변경함. 차감 후 최소값은 0초임.
- 빗나가거나 박스 등 보상 제외 대상만 맞힌 경우 감소하지 않음.
- 변신 중 피해에는 적 대상에 한해 백어택 배율을 적용함.

원본 클립 전체 길이를 실제 돌진시간과 동일하게 사용하지 않음. 돌진·타격 및 행동 종료 구간은 애니메이션 적용 단계에서 조정함.

## 8. 일반 E — 단검 강화와 강타

### 8.1 강화 준비

- E 사용 시 Buff 동작을 시작하고 동시에 강화 효과를 적용함.
- Buff는 임시 3배속, 약 0.5초로 재생함.
- Buff 중 기본 공격·Q·R·간파 입력을 무시하며 예약하지 않음. 이동·대시는 기존 공통 처리 기준을 따름.
- Buff에는 무적을 적용하지 않음.
- 강화는 시간 제한 없이 유지하고 강화 중 E를 중복 사용할 수 없음.
- E를 준비하는 것만으로는 쿨타임을 시작하지 않음.

### 8.2 강화 기본 공격

- Buff 종료 후 기본 공격을 시작하면 일반 4타 대신 Combo_Attack_02_01 강타 1회를 사용함.
- 기본 공격 입력이 실제로 받아들여져 강타가 시작되면 강화 효과를 소모하고 E 쿨타임을 시작함.
- 사용할 수 없는 시점의 입력은 무시하고 강화 소모·쿨타임 시작도 하지 않음.
- 강타 적중 여부와 관계없이 강화 효과는 소모되고 쿨타임도 진행함.
- 유효 대상에게 적중하면 R 스택을 1개 획득함. 여러 대상을 맞혀도 1개만 획득함.
- Q 사용에는 강화 효과를 소모하지 않음.
- 강타 이후 일반 기본 공격 순서를 1타로 초기화함.
- 강타 중 Q·E·R은 일반 공격과 동일하게 입력 무시·예약 없음으로 처리함.

### 8.3 강화 제거와 쿨타임

- 강화 준비 상태에서 변신·쓰러짐·사망이 발생하면 강화 효과를 제거하고 그 시점부터 일반 E 쿨타임 6초를 시작함.
- 이미 강타를 시작하여 쿨타임이 진행 중이라면 다시 시작하지 않고 남은 시간을 유지함.
- 준비된 강화가 없다면 변신·쓰러짐·사망만으로 새 E 쿨타임을 만들지 않음.

## 9. 변신 E — 원형 5타 공격

### 9.1 조준

- E 입력으로 조준 상태에 진입함.
- 원형 범위의 중심은 플레이어에서 일정 거리 떨어져 있고 마우스 방향에 따라 플레이어 주변을 회전함. 마우스 위치까지 자유롭게 범위 중심을 이동하지 않음.
- 조준 중 WASD 이동은 가능함. 공격을 시작하기 전에는 무적을 적용하지 않음.
- 좌클릭으로 범위 위치를 확정하고 공격을 시작함.
- 조준 단계에서 변신 시간 만료 또는 유효한 R 수동 해제가 발생하면 조준을 취소하고 변신을 종료함. 공격을 시작하지 않았으므로 변신 E 쿨타임은 발생하지 않음.
- 공통 조준 취소 조작키는 기존 입력 구현을 따르며 본 문서에서 새 키를 지정하지 않음.

### 9.2 공격

- 공격 시작 시 실제 플레이어 위치와 원형 범위 중심을 고정함. 접근 이동이나 순간이동을 추가하지 않음.
- Skill_02의 모델 움직임은 연출로 사용하며 실제 플레이어 좌표를 이동하지 않음.
- 애니메이션에서 5번 베는 동작에 맞춰 동일 피해의 타격을 5회 적용함.
- 각 타격 시점마다 원형 범위 안의 대상을 확인함.
- 범위에 벽·오브젝트가 있어도 그 너머 범위 안의 적에게 피해를 적용함. 시야 차단이나 경로 차단으로 공격 대상을 제외하지 않음.
- 공격 중 이동·대시·다른 스킬을 사용할 수 없고 입력을 예약하지 않음. R 수동 해제는 공격 후 변신 종료 요청으로 처리함.
- 공격 시작부터 공격 동작 종료까지 무적을 적용함. 강제 중단 시 무적도 제거함.
- 변신 시간 만료 또는 유효한 수동 해제 요청이 있더라도 5타를 완료한 뒤 종료함.
- 쓰러짐·사망은 완료 대기보다 우선하며 남은 타격을 취소함. 무적이므로 일반 피해로 쓰러지는 경우와 강제 상태 전환은 구분함.

### 9.3 임시 수치

| 항목 | 임시값 |

| 타격당 피해 / 타수 | 공격력 ×2.8 / 동일 피해 5타 |
| 총피해 / 백어택 적용 총피해 | 공격력 ×14 / ×16.8 |

쿨타임을 최대 변신시간보다 길게 설정하여 기본 수치에서는 변신당 한 번 사용하는 형태임. 횟수를 강제로 제한하는 별도 규칙은 사용하지 않음.

## 10. R — 변신

### 10.1 사용 조건과 시작

- 일반 상태에서 스택 1개 이상, R 쿨타임 종료, 행동 가능 조건을 충족해야 시전함.
- 0스택이면 사용할 수 없음.
- Parry_R 동작 시작과 동시에 보유 스택을 전부 소모하고 변신 효과와 시간 계산을 시작함.
- 일반 E 강화가 준비되어 있으면 제거하고 일반 E 쿨타임을 시작함.
- Parry_R 중 이동·대시·기본 공격·다른 스킬을 사용할 수 없음.
- 무적은 없으며 피해를 정상적으로 받음.
- 일반 피격·경직으로 Parry_R과 변신을 중단하지 않음. 쓰러짐·사망은 즉시 중단함.

### 10.2 지속시간과 수동 해제

| 소모 스택 | 변신 지속시간 — 임시값 |
|---|---|
| 1개 | 4초 |
| 2개 | 6초 |
| 3개 | 8초 |
| 4개 | 10초 |

- 변신 시작 후 2초간 R 해제 입력을 무시하고 예약하지 않음.
- 2초가 지난 뒤 R 재입력으로 수동 해제를 요청할 수 있음.
- 행동 중이 아니면 즉시 종료함. 공격 중이면 현재 공격을 마친 뒤 종료함.
- 시간 만료도 동일한 현재 공격 완료 기준을 사용함.
- 종료 요청 후 새로운 공격이나 다음 기본 공격 묶음을 시작하지 않음.
- 스택은 반환하지 않음.
- 실제 변신 종료 시점부터 R 쿨타임 8초를 시작함.

### 10.3 공격 완료 기준

| 실행 상태 | 변신 종료 처리 |
|---|---|
| 변신 기본 공격 | 현재 4타 묶음까지 완료 |
| 변신 Q | 현재 Q 공격 동작까지 완료 |
| 변신 E 조준 | 조준 취소 후 종료. E 쿨타임 없음 |
| 변신 E 공격 | 현재 5타 전체 완료 |
| 우클릭 간파 | 현재 간파 공격 동작 완료 |
| 쓰러짐·사망 | 즉시 종료. 현재 공격 완료를 기다리지 않음 |

현재 공격 완료까지 이어지는 시간은 실제 변신 유지시간에 포함함. 해당 공격이 끝나기 전까지 변신 공격의 성능과 백어택 효과를 유지함.

## 11. 우클릭 — 간파

- 일반·변신 모두 Attack_Up_01을 사용하고 기존 캐릭터와 같은 간파 성능을 사용함.
- 다른 공격·스킬 동작 중 우클릭 입력은 무시하고 예약하지 않음. 동작 종료 후 재입력해야 함.
- 간파 동작 중 기본 공격·Q·E·R 신규 시전은 불가함. 변신 R 수동 해제는 종료 대기로 구분함.
- 무기를 올려치는 순간에 피해와 간파 판정을 적용함.
- 범위·피해·쿨타임·넉백 수치는 기존 공통 간파 설정을 사용함. 암살자 전용 수치를 추가하지 않음.
- 간파 중 이동·대시 가능 여부는 기존 캐릭터의 실제 구현을 확인해 동일하게 적용함.
- 보스 일반 상태의 간파는 공통 유효구간과 보스 전방 120도 조건을 따름.
- 보스 취약 상태에서는 전방 조건 없이 공통 넉백·일반 패턴 중단을 적용함. 단순 적중만으로 간파 게이지를 감소시키지 않음.
- 게이지·취약·제압 및 환경 상호작용은 공통 전투 시스템을 호출함.

간파의 성공 방향 조건과 피해의 백어택 판정은 별개임. 변신 중 백어택 피해가 적용되더라도 간파 성공에 필요한 보스 전방 조건을 면제하지 않음.

## 12. 쿨타임 관리와 상태 종료

### 12.1 별도 쿨타임

- 일반 Q·변신 Q·일반 E·변신 E를 별도로 관리함.
- 현재 사용하지 않는 상태의 쿨타임도 계속 감소함.
- 변신 시작·종료만으로 쿨타임을 초기화하지 않음. 일반 E 강화 제거로 시작되는 쿨타임은 예외 조건으로 명시함.
- 피해를 주지 못해도 이미 실행한 공격의 쿨타임은 유지함.

### 12.2 쓰러짐·사망

1. R 스택을 0으로 초기화함.
2. 일반 E 강화가 준비되어 있으면 제거하고 E 쿨타임 6초를 시작함.
3. 진행 중인 공격·조준을 즉시 취소하고 아직 발생하지 않은 타격을 제거함.
4. 이미 적용한 피해는 유지함.
5. 변신 중이었다면 즉시 일반 상태로 돌아가고 R 쿨타임 8초를 시작함.
6. 이미 진행 중인 다른 스킬의 쿨타임은 다시 시작하거나 초기화하지 않고 계속 감소함.

변신 종료 완료 대기보다 쓰러짐·사망이 우선함. 변신 중이 아니었다면 쓰러짐·사망만으로 새 R 쿨타임을 만들지 않음.

| 변신 E 조준 중 시간 만료·수동 해제 | 조준 취소 후 종료. E 쿨타임 없음 |

| 쓰러짐·사망 | 남은 공격 취소, 변신 즉시 종료, 스택 초기화 |

## 16. 개발 적용 시 확인 항목

- 모든 선택 클립의 실제 타격·행동 종료 구간은 애니메이션 적용 단계에서 지정함. 원본 이벤트를 그대로 사용할 수 있다고 가정하지 않음.
- Q의 0.2초는 실제 이동시간이며 원본 클립 전체 길이가 아님. 일반·변신 Q의 최종 행동 연결 시점을 맞춰야 함.
- 일반 기본 공격·강타·Q·간파의 대시 취소와 동작 중 이동은 기존 캐릭터 구현과 비교하여 동일하게 적용함. 본 문서로 새 공통 입력 규칙을 만들지 않음.
- 변신 E의 조준 취소키, 저지불가가 대응하는 상태 이상 목록은 기존 공통 규칙을 확인함.
- 간파의 공통 피해·범위·쿨타임·판정까지 걸리는 시간은 기존 공통값을 사용함.
- 간파용 클립 타격 순간과 공통 판정까지의 시간이 어긋나면 애니메이션 속도·연결 구간을 조정함.
- 다른 기믹 오브젝트의 적중 보상은 해당 기믹에서 지정함. 현재 명시적으로 승인된 기믹 대상은 송전기임.
- UI·VFX·SFX의 신규 제작 목록과 네트워크 판정 권한은 별도 구현·리소스 작업 범위로 남김.

## 17. 개발 확인 목록

- 일반 4타가 좌클릭 유지로 반복되고, 중간 클릭 입력을 예약하지 않는지 확인함.
- 버튼을 놓았을 때 현재 타·현재 묶음만 완료하는지 확인함.
- 강타는 별도 공격으로 실행되고 이후 일반 공격 1타로 복귀하는지 확인함.
- 강타 빗나감과 성공 모두 강화가 소모되고 쿨타임이 시작되는지 확인함.
- 강타 입력이 무시되면 강화가 유지되고 쿨타임도 시작되지 않는지 확인함.
- 여러 적·송전기 적중으로 스택·변신 Q 쿨타임 감소가 중복되지 않는지 확인함.
- 보스는 타격마다 후방 판정을 갱신하고, 변신 중 적에는 자동 백어택·기믹 오브젝트에는 백어택 제외가 적용되는지 확인함.
- Q가 보스를 통과하며 벽 직전에는 종료되는지 확인함.
- 변신 E의 실제 좌표·원형 범위는 고정되고 모델만 움직이는지 확인함.
- 변신 E의 각 타격에 현재 범위 안의 적이 적용되고 지형 차단을 검사하지 않는지 확인함.
- R의 시간 계산·스택 소모는 Parry_R 시작 시점에 발생하는지 확인함.
- 일반·변신 Q·E의 쿨타임이 별도이며 비활성 상태에서도 감소하는지 확인함.
- R 해제 제한 2초, 공격 완료 후 종료, 조준 취소 시 E 쿨타임 없음이 구분되는지 확인함.
- 쓰러짐·사망이 모든 공격 완료 대기보다 우선하고 남은 타격·무적·강화가 남지 않는지 확인함.
