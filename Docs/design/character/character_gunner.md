## 1. 캐릭터 개요

### 1.1 전투 방향

- 대형 레이저포를 양손으로 들고 사용하는 원거리 캐릭터임.
- 기본 공격 중 이동할 수 없는 대신 긴 사거리와 높은 피해를 가짐.
- 마우스 위치에 따라 공격 방향을 즉시 변경할 수 있음.
- 기본 공격으로 과열도를 쌓아 공격을 강화하고, 자동 냉각 또는 E 스킬로 과열도를 관리함.
- Q와 궁극기는 시전 시작 시점의 과열 단계를 저장하여 피해와 보호막을 계산함.
- 우클릭은 보스의 간파 가능 패턴에 대응하고, 취약 상태의 보스를 밀어 환경 상호작용으로 연결하는 근접 간파 스킬임.

### 1.2 다른 캐릭터 및 기존 원거리 기획과의 관계

- 본 문서의 원거리 캐릭터는 기존 원거리 캐릭터 개발 슬롯과 모델을 사용하는 기획임.
- 징크스는 대형 무기를 몸 옆에 들고 사용하는 자세의 참고 대상이며, 별도 플레이어 캐릭터를 의미하지 않음.
- 기존 원거리 캐릭터의 스택 폭발 기획은 본 문서의 과열 기획으로 교체함.

### 1.3 전투 흐름

1. 기본 공격을 반복하여 과열 단계를 높임.
2. 높은 과열 단계에서 강화된 기본 공격을 유지하거나 Q·궁극기를 사용함.
3. 과열도가 최대치에 도달하면 기본 공격이 잠김.
4. 자동 냉각을 기다리거나 E를 사용하여 과열도를 0으로 만듦.
5. 보스가 간파 가능 패턴을 시도하면 가까이 접근하여 우클릭으로 대응함.

## 2. 조작 구성

| 입력 | 기능 |
|---|---|
| 마우스 왼쪽 버튼 유지 / 클릭 | 기본 공격 반복 (유지 시 연사, 입력 창 안 재클릭 시 연속 공격) |
| Q | 충전 레이저 시작 |
| Q 충전 중 마우스 왼쪽 버튼 | 현재 조준 방향으로 Q 발사 |
| E | 냉각 백스텝 |
| 마우스 오른쪽 버튼 | 근접 간파 스킬 |
| R | 궁극기 대상 지정 모드 진입 |
| R 대상 지정 중 마우스 왼쪽 버튼 | 대상 확정 및 궁극기 시전 |

### 2.1 공통 조준 규칙

- 공격 방향은 캐릭터 위치에서 마우스 월드 좌표를 향하는 수평 방향으로 계산함.
- 높이 차이가 있는 경우 게임의 공통 조준 보정 규칙을 적용함.
- 캐릭터 회전은 마우스 방향으로 즉시 변경함.
- 천천히 회전하거나 별도의 회전 속도를 적용하지 않음.
- 각 공격의 실제 판정 방향은 해당 공격 판정이 발생하는 순간의 조준 방향을 사용함.

### 2.2 공통 행동 제한

- 쓰러짐, 완전 사망 또는 조작 불가 상태에서는 새로운 공격과 스킬을 시작할 수 없음.
- 행동 중 쓰러지거나 완전히 사망하면 진행 중인 준비, 충전 및 대상 지정 상태를 종료함.
- 이미 생성된 궁극기 레이저는 시전자 상태와 관계없이 자체 지속시간이 끝날 때까지 유지함.
- 씬 전환, 런 종료 또는 전투 강제 종료 시 캐릭터가 생성한 모든 공격 판정을 제거함.

## 3. 행동 및 입력 우선순위

### 3.1 기본 원칙

- 현재 공격의 판정 구간을 다른 스킬 입력으로 즉시 취소하지 않음.
- 사용할 수 없는 시점에 입력된 스킬은 예약하지 않음.
- 해당 행동이 끝난 뒤 사용하려는 버튼을 다시 입력해야 함.
- 피격 등으로 행동이 강제로 취소되는지는 플레이어 공통 상태 규칙을 따름.

### 3.2 기본 공격과 다른 스킬

- 홀드 또는 입력 창으로 이어지는 각 발사는 하나의 공격 동작으로 처리함.
- 현재 발사의 준비·판정·후속 동작 중 Q, E, 우클릭 또는 R을 입력하면 해당 입력을 무시함.
- 무시된 입력은 현재 공격 종료 후 자동으로 실행하지 않음.
- 다른 스킬을 사용하려면 왼쪽 버튼을 놓고 입력 창 안 재클릭도 멈춘 뒤, 현재 기본 공격 동작이 끝나면 다시 입력해야 함.

### 3.3 Q 충전 중 입력

- Q 충전 중 왼쪽 버튼은 기본 공격이 아니라 Q 발사 입력으로 사용함.
- Q를 다시 입력해도 충전을 취소하지 않음.
- Q 충전 중 E, 우클릭 및 R 입력은 실행하지 않으며 예약하지 않음.
  - 🆕 확정(D1·D2): **공용 대시**는 Q 충전을 끊는다 — 발사 없이 재사용 대기시간 적용.
- 최대 유지시간까지 직접 발사하지 않으면 자동으로 발사함.
- 쓰러짐, 사망 또는 조작 불가 상태가 되면 Q 충전을 강제로 종료하고 발사하지 않음.
- 강제 종료로 실제 레이저가 발사되지 않은 경우 재사용 대기시간을 시작하지 않음.

### 3.4 R 대상 지정 중 입력

- R 입력 시 기존 캐릭터의 타겟팅 궁극기와 같은 대상 지정 모드를 사용함.
- 대상 지정 중 이동할 수 있음.
- 유효한 적을 왼쪽 버튼으로 선택하면 궁극기를 시전함.
- 빈 공간이나 유효하지 않은 대상을 선택하면 시전하지 않음.
- 대상이 확정되지 않은 상태에서 R을 다시 입력하면 대상 지정을 취소함.
- 대상 지정 취소 시 재사용 대기시간을 적용하지 않음.
- 쓰러짐, 사망 또는 조작 불가 상태가 되면 대상 지정을 취소함.

## 4. 기본 공격

### 4.1 기능

- 🆕 변경(2026-10-09): **홀드 연사 + 입력 창 연속 공격 공존**(10-08 의 "클릭 단발 전용"을 되돌려 홀드 연사를 다시 넣음).
- 마우스 왼쪽 버튼을 누르면 짧은 준비 동작 후 레이저를 1발 발사함. 준비 동작은 첫 발만 — 이어지는 발은 거치지 않음.
- 다음 발은 아래 둘 중 **하나만 만족해도** 나감. 둘 다 아니면 이어 쏘지 않음.
  - **홀드**: 버튼을 누르고 있으면 발사 간격(`fireInterval`)마다 계속 발사함. 홀드로 시작해도 준비 동작 1회 후 연사함.
  - **입력 창**: 발사 후 입력 창(직전 발사 기준 `comboWindowOpen`~`comboWindowClose` 초)이 열린 동안 다시 클릭하면 다음 1발로 이어감.
    팔라딘 기본 공격의 콤보 창(ComboWindowOpen~Close)과 같은 방식이며, 창은 애니메이션 이벤트가 아니라 데이터의 시간 값으로 정함.
- 두 경로 모두 다음 발은 직전 발사 후 발사 간격(`fireInterval`)이 지나야 나감(간격 수치 공유, 별도 수치 없음).
- 창 안에서 클릭한 뒤 계속 누르고 있으면 홀드로 연사가 이어지고, 떼면 다시 입력 창 규칙을 따름.
- 창 밖 클릭은 예약하지 않음(누른 채 유지하면 홀드로 이어짐). 공격이 끝나 대기 상태로 돌아간 뒤의 클릭은 새 공격(준비 동작부터)임.
- 네트워크: 오너는 버튼 눌림·뗌과 조준만 서버에 알리고, 첫 발 이후의 발사 시점은 서버가 정함. 홀드 중 오너 신호가 끊기면 서버가 뗀 것으로 보고 마무리함.
- 공격 중에는 이동할 수 없음.
- 공격 방향은 마우스 위치에 따라 즉시 변경할 수 있음.
- 공격 판정은 발사 시점에 즉시 적용하는 직선 판정 방식임.

### 4.2 적중 규칙

- 캐릭터에서 조준 방향으로 설정된 사거리만큼 직선 판정을 실행함.
- 판정 경로에서 가장 먼저 충돌한 유효한 적 1체에게 피해를 적용함.
- 첫 번째 적 뒤에 있는 적에게는 피해를 적용하지 않음.
- 기본 공격은 적과 공격 가능한 오브젝트를 관통하지 않음.
- 지형 또는 공격을 막는 오브젝트에 먼저 닿으면 그 지점에서 판정을 종료함.
- 한 번의 발사로 같은 대상에게 피해를 중복 적용하지 않음.
- 기본 공격 적중 시 추가 상태 이상이나 넉백을 적용하지 않음.
- 허공에 공격해도 과열도는 증가함.

### 4.3 입력 종료

- 버튼을 놓았고 입력 창 안 재클릭도 없으면 현재 발사의 판정과 후속 동작(`shotRecovery`)을 정상적으로 마무리함.
- 현재 발사가 끝나면 다음 발사를 시작하지 않고 기본 대기 상태로 돌아감.
- 기본 공격이 끝난 뒤 이동과 다른 스킬 입력이 가능해짐.

### 4.4 과열 연동

- 기본 공격 1회가 실제로 발사될 때마다 과열도를 증가시킴.
- 적중 여부와 관계없이 같은 양을 증가시킴.
- 과열 상태에서는 기본 공격을 시작할 수 없음.
- 발사로 과열도가 최대치에 도달하더라도 해당 발사의 피해는 정상 적용함.
- 해당 발사가 끝난 뒤 과열 상태로 전환함.
- 홀드 중이거나 창 안 클릭으로 예약돼 있어도 과열이면 다음 발을 쏘지 않고, 해당 발사의 후속 동작까지 마무리하고 끝남.

## 5. 패시브 - 과열

### 5.1 게이지 구조

- 과열도는 0부터 최대치까지의 게이지로 관리함.
- 과열도 구간은 기본 단계와 강화 1·2·3단계로 구분함.
- 기본 단계에서는 과열 피해 보너스를 적용하지 않음.
- 강화 단계가 높을수록 기본 공격 피해가 증가함.
- 과열도가 최대치에 도달하면 과열 상태로 전환함.

| 구분 | 상태 | 기본 공격 | Q·궁극기 단계 판정 |
|---|---|---|---|
| 기본 단계 | 정상 | 사용 가능 | 기본 단계 저장 |
| 강화 1단계 | 정상 | 피해 증가 | 1단계 저장 |
| 강화 2단계 | 정상 | 피해 증가 | 2단계 저장 |
| 강화 3단계 | 정상 | 피해 증가 | 3단계 저장 |
| 최대치 | 과열 | 사용 불가 | 3단계로 저장 |

### 5.2 증가 규칙

- 기본 공격 발사만 과열도를 증가시킴.
- Q, E, 우클릭 및 궁극기는 과열도를 증가시키지 않음.
- 기본 공격의 적중 여부는 증가량에 영향을 주지 않음.
- 과열 증가량은 기본 공격 1회 기준으로 설정함.
- 과열도가 최대치를 초과하지 않도록 제한함.

### 5.3 일반 냉각

- 마지막 기본 공격 발사 후 냉각 대기시간이 지나면 과열도가 서서히 감소함.
- 냉각 중 기본 공격을 다시 발사하면 냉각을 중단하고 대기시간을 처음부터 다시 계산함.
- Q, 우클릭 및 궁극기 사용은 냉각 대기시간을 초기화하지 않음.
- Q 충전 또는 궁극기 시전 중에도 냉각 조건을 충족하면 과열도가 감소함.
- 과열도가 0이 되면 감소를 중단함.

### 5.4 과열 상태 냉각

- 과열 상태에서는 기본 공격을 사용할 수 없음.
- 과열 상태도 지정된 냉각 대기시간 이후 과열도가 서서히 감소함.
- 과열 상태의 감소 속도는 일반 상태보다 빠르게 적용함.
- 과열 상태는 과열도가 0이 되었을 때 종료함.
- 과열 상태가 끝나기 전에는 과열도가 최대치보다 낮아졌더라도 기본 공격을 사용할 수 없음.

### 5.5 E에 의한 강제 냉각

- E 사용 시 과열도를 즉시 0으로 변경함.
- 과열 상태라면 즉시 해제함.
- 과열 단계와 냉각 대기시간도 초기 상태로 변경함.

### 5.6 단계 저장 규칙

- Q와 궁극기는 시전이 시작되는 순간의 과열 단계를 저장함.
- 과열 상태에서 시작하면 강화 3단계를 저장함.
- 시전 도중 과열 단계가 감소하거나 E로 과열도가 0이 되어도 저장된 단계는 변경하지 않음.
- 저장된 단계는 해당 Q 공격 또는 해당 궁극기가 종료될 때까지 유지함.
- 이미 생성된 공격의 계산값을 나중에 다시 계산하지 않음.

### 5.7 초기화

- 런 시작 시 과열도를 0으로 설정함.
- 쓰러짐 또는 부활만으로 과열도를 초기화하지 않음.
- 캐릭터가 완전히 사망해도 같은 런에 복귀할 수 있는 구조라면 기존 과열도를 유지함.
- 씬 전환, 런 종료 또는 캐릭터 재생성 시 과열도를 0으로 초기화함.

## 6. Q - 충전 레이저

### 6.1 사용 순서

1. Q를 입력하면 충전을 시작함.
2. 충전 시작 순간의 과열 단계를 저장함.
3. 충전 중 마우스 방향을 변경할 수 있음.
4. 충전 중 왼쪽 버튼을 입력하면 현재 조준 방향으로 발사함.
5. 최대 충전시간에 도달하면 최대 사거리가 됨.
6. 최대 사거리 도달 후 추가 유지시간이 끝나면 현재 조준 방향으로 자동 발사함.
7. 레이저가 발사된 순간부터 재사용 대기시간을 계산함.

### 6.2 충전 규칙

- 충전 시간은 최소 사거리부터 최대 사거리까지의 사거리 계산에만 사용함.
- 피해량과 보호막량은 충전 시간의 영향을 받지 않음.
  - 🆕 확정(D3·D4): **피해량은 집중 시간에 따라 최소→최대로 보간**한다. 보호막량만 충전 시간 영향 없음. 최소 충전시간 없음.
- 최대 사거리에 도달한 뒤에는 사거리가 더 증가하지 않음.
- 최대 사거리 도달 후 자동 발사까지 짧은 유지시간을 제공함.
- 충전 중 이동할 수 있지만 이동속도 감소 효과를 적용함.
- 충전 중 캐릭터는 마우스 방향을 계속 바라봄.
- 과열 상태에서도 Q를 사용할 수 있음.
- Q는 현재 과열도를 증가시키거나 감소시키지 않음.

### 6.3 판정 규칙

- 캐릭터 위치에서 조준 방향으로 굵은 직선 범위를 생성함.
- 적, 아군 및 공격 가능한 오브젝트를 모두 관통함.
- 지형 또는 관통할 수 없는 월드 오브젝트에 닿으면 그 지점에서 종료함.
- 범위 안에 있는 모든 적에게 피해를 1회 적용함.
- 범위 안에 있는 모든 아군에게 보호막을 1회 적용함.
- 범위 안에 있는 공격 가능한 오브젝트에는 오브젝트 공통 피격 규칙을 적용함.
- 시전자 자신에게는 보호막을 적용하지 않음.
- 같은 Q 한 번으로 같은 대상에게 피해 또는 보호막을 중복 적용하지 않음.

### 6.4 피해 및 보호막 계산

- 저장된 과열 단계에 따라 Q 피해량과 보호막량을 증가시킴.
- 피해 증가 배율과 보호막 증가 배율은 서로 다른 데이터로 설정할 수 있음.
- 발사 시점의 현재 과열 단계가 아니라 충전 시작 시 저장한 단계를 사용함.

### 6.5 보호막 중첩

- Q 보호막은 보호막 수치와 지속시간을 가짐.
- 기존 보호막이 있는 대상에게 다시 적용할 수 있음.
- 재적용된 보호막은 기존 보호막에 합산함.
- 각 보호막은 생성된 시점부터 자신의 지속시간을 별도로 계산함.
- 한 보호막의 지속시간이 끝나면 해당 보호막 수치만 제거함.
- 피해를 받을 때는 남은 지속시간이 가장 짧은 보호막부터 소모함.
- 보호막 총량이 0이 되면 보호막 효과를 제거함.

예시:

1. 보호막 100을 획득하고 5초 지속함.
2. 2초 뒤 같은 Q로 보호막 100을 추가 획득함.
3. 일시적으로 총 보호막은 200이 됨.
4. 첫 보호막의 남은 3초가 끝나면 해당 100만 제거됨.
5. 두 번째 보호막은 자신의 남은 2초 동안 유지됨.

### 6.6 강제 종료

- Q 충전 중 쓰러짐, 완전 사망 또는 조작 불가 상태가 되면 충전을 종료함.
- 강제 종료 시 레이저를 발사하지 않음.
- 실제 발사가 발생하지 않았으므로 재사용 대기시간을 시작하지 않음.
- 이동속도 감소와 충전 연출을 즉시 제거함.

## 7. E - 냉각 백스텝

### 7.1 기능

- 무기 전방으로 냉기를 분출하고 반동으로 조준 방향의 반대쪽으로 짧게 이동함.
- 사용 즉시 과열도를 0으로 만들고 과열 상태를 해제함.
- 과열도가 0이어도 이동 목적으로 사용할 수 있음.
- 피해, 넉백, 기절 및 다른 상태 이상을 적용하지 않음.
- 무적 효과를 적용하지 않음.

### 7.2 이동 방향

- E 입력 순간의 조준 방향을 저장함.
- 저장한 조준 방향의 정확한 반대 방향으로 이동함.
- 이동 입력키의 방향은 E 이동 방향에 영향을 주지 않음.
- E 이동 중 마우스를 움직여도 이미 저장한 이동 방향은 변경하지 않음.

### 7.3 충돌 처리

- 적, 아군, 벽 및 오브젝트를 통과할 수 없음.
- 이동 경로에 충돌 대상이 있으면 충돌 직전 위치에서 이동을 종료함.
- 충돌로 이동 거리가 짧아져도 과열도 초기화 효과는 정상 적용함.
- 맵 밖이나 이동 불가능 지역으로 이동하지 않음.

### 7.4 입력 및 종료

- 기본 공격 중 입력된 E는 기본 공격을 취소하지 않음.
- 기본 공격을 중단하고 현재 발사 동작이 끝난 뒤 E를 다시 입력해야 함.
- E 동작 중 다른 공격과 스킬을 시작할 수 없음.
- E 동작 종료 후 기본 공격을 포함한 다른 행동을 사용할 수 있음.
- 과열 상태는 E 사용 시점에 해제되지만 기본 공격은 E 동작 종료 후 사용할 수 있음.

## 8. 우클릭 - 근접 간파 스킬

### 8.1 기능

- 대형 레이저포를 뒤로 당긴 뒤 전방으로 강하게 내지르는 근거리 공격임.
- 무기를 내지른 시점에 근접 판정을 먼저 실행함.
- 총구가 대상과 맞닿는 시점에 피해와 간파 판정을 적용함.
- 이후 레이저와 폭발 VFX를 출력함.
- 과열도를 증가시키거나 감소시키지 않음.
- 별도의 충격량 스탯을 사용하지 않음.
- 다른 플레이어 캐릭터의 간파 스킬과 성능 규칙을 동일하게 사용하고 동작과 연출만 다르게 구성함.

### 8.2 일반 상태의 보스

- 보스가 간파 가능 패턴의 유효 구간에 있을 때만 간파 성공이 가능함.
- 공격이 보스 전방 120도 범위 안에서 적중해야 간파에 성공함.
- 조건을 충족하면 현재 패턴을 중단하고 보스를 취약 상태로 전환함.
- 간파할 수 없는 패턴이나 유효 구간이 아닌 상태에서는 피해만 적용함.
- 전방 120도 조건을 충족하지 못하면 간파에 실패하고 피해만 적용함.

### 8.3 취약 상태의 보스

- 취약 상태에서는 전방 120도 조건을 사용하지 않음.
- 간파 스킬이 적중하면 보스를 공격한 플레이어의 반대 방향으로 밀어냄.
- 넉백 방향은 플레이어에서 보스를 향하는 방향으로 계산함.
- 넉백 적중 시 보스가 실행 중인 일반 공격 패턴을 중단함.
- 취약 상태에서 간파 스킬을 맞히는 것만으로 간파 게이지를 감소시키지 않음.
- 보스가 벽에 충돌하거나 증기 벤트 범위에 들어가는 환경 상호작용에 성공해야 간파 게이지가 감소함.
- 환경 상호작용에 성공하면 취약 상태를 즉시 종료함.

### 8.4 동시 적중

- 같은 판정 구간에 여러 플레이어의 간파 스킬이 적중하면 가장 먼저 서버에서 확정된 1회의 넉백만 적용함.
- 첫 넉백 이후 다른 간파 스킬이 적중하면 새로운 적중 방향을 기준으로 넉백을 다시 적용함.
- 동일 프레임으로 처리된 공격은 서버 판정 순서가 가장 빠른 공격을 첫 적중으로 사용함.
- 각 스킬의 피해는 개별적으로 정상 적용함.

### 8.5 후폭풍 이동

- 공격 적중 여부와 간파 성공 여부에 관계없이 후폭풍 이동을 실행함.
- 캐릭터를 공격 방향의 반대쪽으로 짧게 이동시킴.
- 후폭풍 이동은 실제 캐릭터 좌표를 변경함.
- 후폭풍 이동에는 무적을 적용하지 않음.
- 벽이나 오브젝트에 막히면 충돌 직전 위치에서 종료함.

### 8.6 빗나감 및 대상 없음

- 유효한 대상이 없어도 공격 동작, 레이저·폭발 연출 및 후폭풍 이동은 실행함.
- 대상이 없으므로 피해와 간파 판정은 발생하지 않음.
- 스킬을 사용한 것으로 처리하여 재사용 대기시간을 적용함.

---

## 9. 궁극기 - 추적 레이저

### 9.2 대상 지정

- R을 입력하면 대상 지정 모드에 진입함.
- 지정 가능 범위 안의 유효한 적만 선택할 수 있음.
- 유효한 적을 왼쪽 버튼으로 선택하면 대상을 확정함.
- 빈 공간을 선택하면 시전하지 않으며 재사용 대기시간도 적용하지 않음.
- 대상 지정 중 R을 다시 입력하면 취소함.
- 대상 확정 순간의 과열 단계를 저장함.

### 9.3 생성 및 독립 행동

- 대상이 확정되면 해당 대상의 현재 위치에 대형 레이저를 생성함.
- 레이저가 생성된 순간부터 지속시간과 재사용 대기시간을 계산함.
- 레이저 생성 후 플레이어는 자유롭게 이동하고 다른 행동을 사용할 수 있음.
- 플레이어가 쓰러지거나 완전히 사망해도 이미 생성된 레이저는 제거하지 않음.
- 궁극기는 과열도를 증가시키거나 감소시키지 않음.
- 기본 궁극기에는 보호막 효과가 없음.

### 9.4 추적 규칙

- 레이저 중심은 지정된 대상을 정해진 이동속도로 추적함.
- 대상을 향해 즉시 순간이동하지 않음.
- 대상이 레이저보다 빠르게 이동하면 피해 범위에서 벗어날 수 있음.
- 추적 대상이 살아 있고 유효한 동안에는 다른 적으로 대상을 변경하지 않음.
- 대상이 사망하거나 제거되면 레이저 주변의 재탐색 범위 안에서 가장 가까운 살아 있는 적을 찾음.
- 거리가 같은 대상이 여러 명이면 서버에서 먼저 확인된 유효 대상을 선택함.
- 새로운 적을 찾으면 즉시 새 추적 대상으로 지정함.
- 새 대상을 찾지 못하면 현재 위치에 머무르며 일정한 탐색 간격으로 다시 탐색함.
- 새로운 대상을 찾지 못해 대기하는 시간도 궁극기 지속시간에 포함함.

### 9.5 피해 규칙

- 레이저 중심 주변에 원형 피해 범위를 사용함.
- 지정된 피해 간격마다 범위 안의 모든 적에게 지속 피해를 적용함.
- 한 번의 피해 주기에서는 같은 대상에게 피해를 1회만 적용함.
- 대상이 범위를 벗어나면 피해를 받지 않음.
- 다시 범위 안에 들어오면 다음 피해 주기부터 피해를 받을 수 있음.
- 저장된 과열 단계에 따라 각 피해량을 증가시킴.
- 궁극기 도중 현재 과열 단계가 바뀌어도 이미 저장한 단계는 변경하지 않음.

### 9.6 종료 규칙

- 레이저가 생성된 시점부터 정해진 지속시간이 지나면 종료함.
- 추적 대상이 사망해도 궁극기 지속시간과 재사용 대기시간을 초기화하지 않음.
- 적을 찾지 못한 채 대기하더라도 지속시간이 끝나면 제거함.
- 씬 전환, 런 종료 또는 전투 강제 종료 시 즉시 제거함.

## 13. 구현 로직 요약

### 13.1 과열 상태 흐름

```text
기본 공격 발사
  → 과열도 증가
  → 단계 구간 재계산
  → 최대치 도달 여부 확인
    → 미도달: 현재 단계 유지
    → 도달: 현재 발사 종료 후 과열 상태 진입

마지막 기본 공격 이후 냉각 대기시간 경과
  → 과열도 지속 감소
  → 과열 상태라면 빠른 냉각 속도 사용
  → 0 도달 시 기본 단계 및 정상 상태 복귀

E 사용
  → 과열도 0
  → 과열 상태 해제
  → 냉각 대기시간 초기화
```

### 13.2 Q 흐름

```text
Q 입력
  → 사용 가능 여부 확인
  → 현재 과열 단계 저장
  → 충전 상태 진입 및 이동속도 감소
  → 충전 시간에 따라 사거리 계산
    → 좌클릭 입력: 현재 방향으로 발사
    → 최대 유지시간 도달: 현재 방향으로 자동 발사
  → 적 피해 및 아군 보호막 적용
  → 충전 상태와 이동속도 감소 제거
  → 재사용 대기시간 시작
```

### 13.3 궁극기 흐름

```text
R 입력
  → 대상 지정 모드 진입
  → 유효 대상 선택
  → 현재 과열 단계 저장
  → 대상 위치에 추적 레이저 생성
  → 지속시간 시작
  → 대상 추적 및 범위 지속 피해
    → 대상 유효: 계속 추적
    → 대상 사망·제거: 주변에서 가장 가까운 적 탐색
      → 발견: 새 대상 추적
      → 미발견: 현재 위치에서 반복 탐색
  → 지속시간 종료 시 제거
```

## 14. 구현 시 재사용 방향

- 캐릭터 이동, 조준 방향 계산, 공용 대시 및 피해 처리 구조는 기존 플레이어 공통 코드를 사용함.
- R 대상 지정은 기존 타겟팅 궁극기 구조를 재사용함.
- 우클릭의 성공 조건과 보스 상태 전환은 캐릭터 내부에서 별도로 만들지 않고 공통 간파 시스템을 호출함.
- 보스 전방 120도 판정도 공통 간파 시스템에서 처리함.
  - 🆕 확정(D11): 현재 코드는 공격에 간파 표시(`isInterruptAttack`)만 싣고 **보스가 각자 판정**한다(23호 `IsCounterFromFront` 등). 거너는 이 흐름에 올린다.
- Q 보호막은 기존 단일 값 교체 방식으로는 독립 지속시간 중첩을 처리할 수 없으므로, 보호막 인스턴스를 여러 개 관리할 수 있도록 확장해야 함.
- 과열도와 저장된 과열 단계는 해당 캐릭터의 소유권을 가진 플레이어 상태에서 관리하고 멀티플레이 동기화 대상으로 포함해야 함.

## 15. 테스트 항목

### 15.1 기본 공격 및 과열

- 짧게 클릭하면 1발만 나가고, 누르고 있으면 발사 간격마다 연사하는지 확인함.
- 홀드·입력 창 안 재클릭 어느 쪽으로 이어져도 준비 동작이 최초 1회만 실행되는지, 창 밖 짧은 클릭은 이어지지 않는지 확인함.
- 창 안에서 클릭한 뒤 계속 누르면 연사로 이어지고, 떼면 후속 동작 후 끝나는지 확인함.
- 홀드 중 과열되면 그 발의 후속 동작까지 마무리하고 끝나는지 확인함.
- 공격 중 이동이 제한되고 조준 방향은 즉시 바뀌는지 확인함.
- 첫 번째 적만 맞고 뒤의 적은 맞지 않는지 확인함.
- 허공 공격에도 과열도가 증가하는지 확인함.
- 단계 경계에서 피해 배율이 정상적으로 변경되는지 확인함.
- 최대치 도달 발사의 피해가 정상 적용된 뒤 기본 공격이 잠기는지 확인함.
- 일반 냉각과 과열 냉각의 속도가 다르게 적용되는지 확인함.

### 15.2 Q

- 충전 시간에 따라 사거리만 증가하는지 확인함.
- 최대 유지시간이 끝나면 자동 발사되는지 확인함.
- 충전 시작 단계와 발사 시점 단계가 달라도 저장 단계로 계산되는지 확인함.
- 적·아군·오브젝트를 관통하고 각 대상에 한 번만 적용되는지 확인함.
- 여러 보호막의 수치와 지속시간이 독립적으로 처리되는지 확인함.
- 쓰러짐 또는 사망으로 충전이 취소될 때 레이저와 재사용 대기시간이 발생하지 않는지 확인함.

### 15.3 E 및 우클릭

- 과열도와 관계없이 E를 사용할 수 있는지 확인함.
- 이동 경로가 막혀도 과열도는 0이 되는지 확인함.
- E에 무적, 피해 또는 상태 이상이 발생하지 않는지 확인함.
- 우클릭이 간파 가능 패턴과 전방 조건을 모두 충족할 때만 성공하는지 확인함.
- 취약 상태에서는 전방 조건 없이 넉백되는지 확인함.
- 우클릭이 빗나가도 캐릭터 후폭풍 이동이 발생하는지 확인함.

### 15.4 궁극기

- 빈 공간에 시전되지 않고 재사용 대기시간도 적용되지 않는지 확인함.
- 레이저가 고정 속도로 대상을 추적하는지 확인함.
- 대상 사망 시 가장 가까운 유효 대상을 다시 찾는지 확인함.
- 대상이 없을 때 현재 위치에서 재탐색하는지 확인함.
- 시전자 사망 후에도 생성된 레이저가 유지되는지 확인함.
- 생성 시점부터 지속시간이 정확히 계산되는지 확인함.
