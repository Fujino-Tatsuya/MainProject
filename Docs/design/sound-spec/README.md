## 1. 쓰는 법

1. 만들 행을 고른다 → **녹화** 열이 있으면 영상→효과음 도구, `—` 면 텍스트 도구(§5).
2. **프롬프트(EN)** 를 그대로 붙여 넣는다. 길이·느낌은 행에 있는 값으로 조절.
3. 결과에서 쓸 구간을 잘라 `Assets/51.Audio/SFX/<카테고리>/` 에 넣고(SVN — `.meta` 같이 커밋), xlsx `Sound` 시트에 **키 이름 그대로** 행 추가 → `Tools/Data/사운드 동기화`([handoff-sound-sync.md](../../tech/handoff-sound-sync.md), [data-table.md §6](../../tech/data-table.md)).
4. 행의 **상태** 열을 고친다(❌ → ⚠️ 임시 → ✅).

## 2. 표 읽는 법

| 열 | 뜻 |
|---|---|
| 키 | 카탈로그 키. 규칙 `<주체>_<동작>[_<단계>]`, 루프는 `_Loop`. 여러 키를 한 행에 쓴 경우 `/` 로 구분 |
| 언제 | 게임 안 트리거(사람 말) + 코드 위치 |
| 듣는 사람 | **전원**(서버가 복제한 상태·RPC·애니 이벤트를 각 PC 가 받아 각자 재생) / **오너**·**나만**(내 화면만) / 다른 사람(본인 제외) |
| 2D·3D | 3D 면 최소~최대 감쇠 거리(m) 제안값 → `SoundEntry.is3D` · 감쇠 칸. 탑다운 카메라라 리스너는 플레이어 위치(`PlayerAudioListenerActivator`) |
| 길이·반복 | 초 · OneShot/루프 · **변형 N**(같은 키에 클립 N개 → 랜덤 재생) · **재생 제한**(연사·다중 적중처럼 한 프레임에 여러 번 날 수 있는 것) |
| 느낌 · 레퍼런스 | 한국어 한 줄 + 참고 게임/소리 |
| 짝 VFX | 이미 있는 VFX 엔트리 이름. **그 엔트리의 `EffectPart.sound` 에 키를 넣으면 VFX 와 같은 프레임에 전 피어에서 울린다**(`EffectManager.cs:612`) — 코드 없이 붙이는 가장 쉬운 길. 루프 VFX 에 넣으면 시작 1회만 |
| 녹화 | 영상→효과음용 촬영 지시. `—` = 텍스트 생성, `(위)` = 바로 위 행과 같은 클립에서 같이 뽑음 |
| 프롬프트(EN) | 생성 도구에 그대로 붙일 문장. `(공용)` = 다른 키 재사용 |
| 상태 | ✅ 있음 · ⚠️ 클립 후보 있음/임시/칸만 있음 · ❌ 없음. "훅 없음" = 소리를 낼 코드 지점 자체가 없음(별도 작업) |

## 3. 전체 톤

- **세계**: 탑다운 SF 공장 · 적은 전부 로봇(서보·유압·금속·전기) · 보스 23호는 거대 전기 격투 로봇. 로비·타이틀은 **레트로 퓨처 단말기**(CRT·릴레이·슬라이드 프로젝터).
- **플레이어**: 팔라딘 = 묵직한 금속 + 성광(금·흰) 공명 / 어쌔신 = 날카롭고 빠름, 변신 시 칼날 바람 / 거너 = 에너지 레이저 + 과열·냉각 증기.
- **우선순위**: 피해야 하는 예고음(적 공격 준비·장판 예고·드론 조준) > 간파 > 내 공격 적중 > 나머지. 예고음은 **바닥 표시가 없는 공격일수록 중요**(23호 훅·어퍼는 소리가 유일한 예고).
- **레퍼런스 묶음**: Ravenswatch(전투 템포) · Hades(타격감·UI) · Sekiro(간파) · Titanfall 2(거대 로봇) · Alien: Isolation(레트로 단말기 UI).
- **믹스 원칙**: 같은 키 연타는 재생 제한 · 간파 소리는 타임스케일 무시(슬로우 중에도 음정 고정) · 3D 감쇠는 보스방 30×30m 기준으로 보스 계열은 넓게.

> 영상→효과음 도구는 **멀티플레이 구분·3D 를 모른다**. 그건 게임(키별 `is3D`·재생 위치·듣는 사람)이 맡는다 — 이 문서의 "듣는 사람"·"2D·3D" 열이 그 설계다.
>
> ⚠️ 2026-10-30 실제 시도 결과: 영상→효과음(Sonilo)은 탑다운에서 캐릭터가 작고 아군 이펙트가 커서 **엉뚱한 대상에 소리가 붙고**, 결과가 섞인 한 트랙이라 키별로 못 나눈다 → **키별 텍스트 생성이 기본**, 영상은 넣은 뒤 검수 녹화용.

## 5.1 제작 규칙 — 생성할 때 · 게임에 넣을 때 (2026-10-30)

> 외부 조사 문서(Gemini 정리, 일반 판타지 RPG 템플릿)에서 쓸 것만 가져오고 우리 경험·코드로 고쳤다.

**프롬프트 틀** — `[스타일 머리] + [동작·재질] + [소리 모양(시작·끝)] + [캐릭터 색] + [금지]`
- **스타일 머리를 맨 앞에 둔다**: `Stylized anime action game skill SFX, not realistic, not foley, not a recording:`
  재질·동작만 쓰면(`metal blade slicing armor` 류) **실사 녹음처럼 나온다**(10-30 1차 생성이 그랬다). 우리 비주얼은 셀 셰이딩 SD·별 모양 섬광·만화풍 연기라 소리도 과장·합성 쪽.
- 소리 모양: 타격·UI = `instant attack, sharp transient` · 끝 = `fast decay, dry, no heavy reverb`(공간감은 게임이 준다). 의성어(`pew`·`BWOOM`·`KANG`)가 모양을 잘 전한다.
- 금지: `no music, no voice`. 거너는 `no realistic firearms` — `gun`·`rifle`·`bullet`·`shot` 단어를 쓰면 실탄 총성이 나온다.
- 키별 완성 문장: `playvideo/sound_clips/text-sfx-prompts.md`(로컬, 플레이어 75키 v2).

**생성 설정**
- 길이 슬라이더를 소리에 맞게 줄인다(기본값이면 뒤에 잡음·꼬리가 붙는다). 도구 최소 길이가 명세보다 길면 **만든 뒤 자른다**.
- 자주 나는 소리(평타·피격·발소리)는 같은 문장으로 3~4개 → 변형(랜덤 재생).

**파일 · 가져오기**
| 항목 | 규칙 |
|---|---|
| 이름 | `<키>_<번호>` (예 `Gunner_Q_Fire_01.wav`) — 자동 검수·xlsx 등록이 이 이름으로 키를 찾는다 |
| 형식 | wav(16bit·44.1/48kHz) 원본 보관. mp3 는 앞에 짧은 무음이 붙기 쉬워 **트림 확인** |
| 채널 | **3D 행 = 모노**(스테레오는 위치감이 흐려진다). 2D(UI·BGM·오너 전용) = 스테레오 가능 |
| 트림 | 앞 무음 30ms 이하, 뒤 무음 제거. 지연이 곧 조작감 |
| 음량 | 분류끼리 맞춘다 — 예고음·간파 > 내 공격 > 환경음 순(§3 우선순위). 생성물은 크기가 제각각이라 등록 전 정규화 |
| Unity 가져오기 | 짧은 효과음 = Decompress On Load · 긴 루프/BGM = Streaming · 3D 효과음 = Force To Mono |

**게임에 넣을 때 (`SoundCatalog` 칸이 이미 있다)**
- 반복음은 `pitchRandomMin/Max` 0.9~1.1 · `volumeRandomMin/Max` 로 피로를 줄인다.
- 같은 키 연타(거너 평타 0.35s·Q 관통 최대 8)는 동시 재생 수를 제한한다.
- 상업 이용: 도구별 약관을 결제·출시 전에 확인(무료 플랜은 비상업인 경우가 많다 — §5).

**자동 1차 검수** — `playvideo/sfx_review/`(로컬, [PLAN-sfx-review.md](../../../PLAN-sfx-review.md)): CLAP + 수치 100점, 기준점 이상 + 무작위 표본만 사람이 듣는다.

## 7. 코드 추가가 필요한 곳 (이 문서 범위 밖 — 소리를 만들어도 바로는 안 남)

- **발소리 전부**(플레이어 3종·몬스터·보스) — 걷기/달리기 클립에 발 이벤트 없음 + 바닥 재질 판정 없음.

- **MortarBot 발사 순간** — 발사 VFX 없음 → 클립 이벤트 필요.
- 몬스터 **기상·인지·벽 충돌**, 23호 **취약 중 벽 반동**, **포효(미구현)** — 화면 신호 없음.
- **호버 소리**(모든 UI · 특성 카드) — 포인터 핸들러 없음.
- **쿨타임 완료·대시 충전·보스 타이머 임박·접속/퇴장 알림** — 완료 이벤트 없음(HUD 폴링).
- **BGM 구간 전환** — `SceneBgmSwitcher` 미사용, 씬 매니저 3곳 하드코딩. 존/전투/보스 페이즈 전환은 이벤트 기반 전환기 필요. 23호 페이즈는 클라로 복제 안 됨.
- **관전 저역 필터**, 거너 **과열 거부**·**대시 충전 없음 거부** 피드백.
