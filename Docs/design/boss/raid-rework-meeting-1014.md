## 결정 요약 (팀장)
- 레퍼런스 = 로스트아크 발탄·쿠크세이튼. 23호만, 새 애니 클립 금지·VFX 가능, 기존 23호 유지 + 변형 추가 후 비교.

- 합본 A+ 채택: ① 기동 시연(Codex) ② 드론 유도 송전 + 방전 실패(Codex + Claude) ③ 구출 각본(Codex) ④ 폐기 처분 자폭(Claude + Codex).
- 버린 것: Claude 의 회로 노드 타일 퍼즐(4주 비용 — 여유 시 후보) · Codex B안(이동·판별 중심 "가족 검사", 쇼는 강하지만 비용 상) · 전멸급 실패(처음 하는 사람에게 불쾌).

## 뼈대: "웰즈의 실험 기록"
웰즈 = 실험자, 23호 = 23번째 실험체(번호 자체가 소모품 서사), 플레이어 = 실험을 망치러 온 침입자.
구간마다 웰즈가 "실험 N" 을 선언(자막 + 화면 VFX) → 쿠크의 "쇼" 자리를 "실험"이 맡는다. 원흉 = **웰즈**(23호는 피해자이자 무기).
마지막 구간에 웰즈가 23호를 **버린다**(소모품 취급 설정의 회수) → 엔딩 감정선.

## 상시 개선 (두 안 공통)
- **인원 HP 보정**: 1인 0.6 / 2인 0.8 / 3인 1.0(현재 없음 — 솔로가 가장 고통). 로아 싱글처럼.
- 잡기 구출 성공 = 23호 그로기 2초(보상으로 "구했다" 체감).
- 페이즈 배수 실제로 쓰기(지금 1·1).
- 기믹 중 상시 장판·드론 일시정지 규칙 통일(정보 과부하 방지).

## 빼는 게 나은 것 (처음 하는 플레이어 기준)
- 상시 전기 장판 + 드론 + 보스 패턴 동시 진행 → 30×30 방에서 읽을 게 너무 많다. 1구간은 장판 끄기(학습 구간).
- 레이지 돌진 3회(실패 대가로 약하고 의미가 안 읽힘) → 방전으로 대체.
- 같은 송전기 2회 반복.

## 4주 우선순위
1. 변형 보스 골격: 새 BossDataSO + **구간 각본 테이블**(HP 임계 → 기믹 시퀀스) + 기존/변형 전환 토글 — 이후 전부의 바닥.
2. 송전기 보상·실패(방전) + 페이즈 배수 + 인원 HP 보정 — 적은 비용, 체감 큼.
3. 폐기 처분 딜 체크 + 웰즈 자막 — 가장 극적, 엔딩.
4. 회로 재배선 노드 기믹 — 새 규칙이라 비용 큼.
5. 드론 장판 협동.

## 위험
- 네트워크: 노드·카운트다운·구간 상태는 서버 권한 + NetworkVariable, 자막은 튜토리얼의 ShowSubtitleServer 패턴 재사용.
- 밸런스: 1인 딜 체크 시간 = 실측 DPS 필요(1주차에 측정).
- 가독성: 각 실험 선언 자막 + 큰 VFX 가 없으면 처음 하는 사람은 규칙을 모른다 → 자막을 규칙 설명으로.

## 원문 B — Codex 안 (codex exec -s read-only, 10-14)

**추천은 A안입니다.** 괴력 로봇을 역이용하고 동료를 구하는 순간이 선명하며, 기존 공격을 재사용하기 좋습니다. B안은 웰즈의 캐릭터성을 앞세운 이동·판별 중심의 대안입니다.
아래 이름·세계관·수치는 모두 **신규 제안**이며, 파일은 수정하지 않았습니다. Unity Play·MPPM 체감은 **미확인**입니다.

**확인한 구현 근거**

- 66%·33%는 같은 송전기이며 피해·속도 배수도 같습니다. [No23.asset](Assets/2.Prefabs/Monster/Data/No23.asset:305)
- 잡기 구출 창은 붙잡은 뒤부터 마지막 내려치기 직전까지 열립니다. [TwentyThreeBoss.cs](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:2126)
- 드론은 현재 플레이어만 해치며 충전 기믹 중에는 취소·정지합니다. 탑 파괴에 쓰려면 새 판정이 필요합니다. [WellsDroneAttack.cs](Assets/1.Scripts/Monster/Boss/WellsDroneAttack.cs:90), [피해 처리](Assets/1.Scripts/Monster/Boss/WellsDroneAttack.cs:194)
- 전기 바닥은 지속 피해가 아닌 예고 후 1회 타격이며, 기본 주기는 약 6.6초입니다. [전기 장판 설계](Docs/design/boss/boss-electric-floor.md:45)

**1. 구간 각본안 2개**

공통: 75%·45%·20%에서 각본을 한 번씩 실행하고, 사이에는 일반 전투를 둡니다.
각본 중에는 무관한 상시 공격을 멈춥니다. 성공 보상 동안도 바닥·드론을 멈춰 공격할 시간을 보장합니다.
인원 변환은 특정 직업을 요구하지 않으며, 실패 대가는 유한하게 끝납니다. 신규 모션은 사용하지 않습니다.

**A안 — 「웰즈의 가족 공장」: 유도 → 파괴 → 구출 → 공동 제압**

**① HP 100→75% / “우리 아이, 힘 좀 보여 줘”**
- 규칙: 첫 훅 두 번 → 긴 예고의 간파 가능한 돌진을 고정 시연. 이후 훅·돌진 중심 일반 전투.
- 변환: 1인=정면 보조 화살표 / 2인=한 명 유도·한 명 간파 가능 / 3인=같은 규칙, 간파는 누구든 한 번이면 충분.
- 성공·실패: 간파 성공=공동 게이지 감소·짧은 공격 기회 / 실패=예고한 돌진 피해, 구간 진행은 유지.
- 재사용: 훅·돌진·간파·방향 표시기 / 신규 코드: 시작 공격 순서 / 신규 VFX: 정면·간파 안내. **난이도 하.**

**② HP 75→45% / “가족에게 전력을”**
- 규칙: 송전탑 활성화, 웰즈가 드론 지목. 탑에 지목을 놓고 원이 고정되면 이탈; 드론 한 발로 탑 파괴. 직접 공격도 허용.
- 변환: 1인=탑 1개 / 2인=2개 / 3인=3개. 드론은 순차 지목하며, 이미 파괴한 탑에는 유도 표시를 지움.
- 성공·실패: 제한시간 25초 내 전부 파괴=제압 5초 / 실패=긴 직선 예고를 붙인 레이지 돌진 3회.
- 재사용: 송전탑·충전 자세·드론·원 예고·레이지 / 신규 코드: 각본 중 드론 실행, 탑 전용 적중·파괴 판정.
- 신규 VFX: 탑과 웰즈를 잇는 전력선·“여기로 유도” 표식. **난이도 중.**

**③ HP 45→20% / “새 가족을 데려와”**
- 규칙: 웰즈의 선언 뒤 잡기 1회. 동료가 정면 간파로 구출; 전원이 피하거나 슈퍼아머로 저항해 헛잡기가 나도 성공.
- 변환: 1인=잡기 대신 간파 가능한 단일 돌진 / 2인=잡힌 사람 외 한 명 구출 / 3인=남은 둘 중 누구든 구출.
- 성공·실패: 회피·간파·구출 성공=제압 5초 / 실패=기존 내려치기 3회 후 반드시 해제; 추가 광역 벌칙은 없음.
- 재사용: 잡기·구속·간파·돌진·Break / 신규 코드: 솔로 교체, 결과 판정, 구출 시간 확보.
- 신규 VFX: “정면에서 구출” 화살표·남은 내려치기 횟수. **난이도 중.**

**④ HP 20→0% / “가족은 고장 나면 버리면 돼”**
- 규칙: 20% 진입 때 충전 자세로 12초 공동 제압 시험. 평타·스킬 피해와 간파가 같은 게이지를 줄임; 이후 잔여 HP 전투.
- 변환: 1/2/3인=같은 행동, 게이지 목표량을 인원별 조정. 시험 중 간파 가능한 돌진을 한 번 제공.
- 성공·실패: 게이지 0=제압 5초·피해 보너스 / 실패=예고 레이지 3회 후 일반 전투로 복귀, 시험 반복 없음.
- 재사용: 공동 게이지·충전·돌진·제압 / 신규 코드: 시험 중 일반 피해의 게이지 환산, 성공·실패 중복 방지.
- 신규 VFX: 과열 균열·전력선 파열; 제압 종료 후 웰즈의 “쓸모없어.” 자막. **난이도 중.**

**B안 — 「웰즈의 완벽한 가족 검사」: 지시 읽기 → 지목 처리 → 이동 시험 → 졸업 시험**

**① HP 100→75% / “착한 아이는 말을 잘 들어”**
- 규칙: 시작에 전기 검사 2회. 위험 타일과 안전 통로를 보여 주고 이동시키며, 이후 훅 중심 일반 전투.
- 변환: 1인=연속 경로 화살표 / 2인=공용 안전 통로 / 3인=같은 통로를 세 명이 들어갈 폭으로 확보.
- 성공·실패: 두 검사 회피=공동 게이지 감소 / 피격=그 검사 피해만 받고 진행; 첫 교육부터 처형하지 않음.
- 재사용: 타일 그리드·마스크·사각 예고 / 신규 코드: 고정 검사 순서·회피 집계 / VFX: 통로 테두리·짧은 지시. **난이도 중.**

**② HP 75→45% / “가족 사진—그 자리에 서 있어”**
- 규칙: “사진 자리” 밖의 폐기칸에 드론을 유도. 지목 추적 → 위치 고정 → 이탈을 읽는 시험; 보스는 충전 자세로 대기.
- 변환: 1인=드론 1회 / 2인=서로 다른 사람에게 순차 2회 / 3인=순차 3회. 동시에 지목하지 않음.
- 성공·실패: 모든 낙하지점을 폐기칸에 놓음=제압 5초 / 실패=보상 없이 예고 돌진 1회; 드론 자체 피해도 유지.
- 재사용: 드론·타일·충전 자세·돌진 / 신규 코드: 지정 칸 적중 검사·대상 순서·각본 중 드론 실행.
- 신규 VFX: 사진 프레임·폐기 표식·위치 고정 순간의 셔터 섬광. **난이도 중.**

**③ HP 45→20% / “불량품 선별 검사”**
- 규칙: 안전 구역이 왼쪽 → 오른쪽 → 중앙으로 세 번 이동. 매 단계 다음 목적지를 먼저 표시; 암기보다 이동 판단을 시험.

**④ HP 20→0% / “완벽한 가족, 마지막 시험”**

- 재사용: 앞 구간의 검사·드론·공동 제압 / 신규 코드: 단계 연결·보상 누적·전체 취소 처리.
- 신규 VFX: 검사 결과 도장·웰즈의 명령선이 끊기는 효과. **난이도 상; 일정 부족 시 단일 제압 시험으로 축소.**

**2. 상시 패턴 개선**

- **잡기 구출:** A안의 핵심 장면으로 승격. 일반 전투 잡기는 빈도를 낮추고, 잡힌 순간 다른 위험을 정지시켜 구출 판단에 집중.
- **드론 지목:** 초반에는 “밖으로 빼기”, 중반에는 “목표물에 놓기”로 발전. 추적 중과 위치 고정 후를 모양·음향으로 구분.
- **페이즈 차등:** 초반 훅·단일 돌진 → 중반 점프 추가 → 후반 훅 연계와 짧아진 회복. 예고 시간은 유지하고 빈도부터 조정.
- **공동 게이지:** 간파·구출·각본 성공을 같은 성취로 연결. 현재 송전탑 성공은 간파 게이지와 별개이므로 연결 작업이 필요합니다. [제압 처리](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:5006)

**3. 세계관 보강 제안**

- **원흉은 웰즈**로 권장. 23호는 명령을 수행하는 파괴 도구로 두면, 낮은 지능과 세계선 교란의 책임을 자연스럽게 연결할 수 있음.
- 송전탑은 “웰즈가 23호를 한계 이상으로 부리는 공장 전력 설비”로 새로 설정. 기존 확정 설정이라는 의미는 아님.
- 초반 “우리 아이는 튼튼해.” → 중반 “아프다는 말은 하지 마.” → 후반 “고장 난 가족은 필요 없어.”
- 기존 충전 자세에 명령선·전력 VFX를 얹고, 23호가 제압돼도 웰즈의 명령 자막은 계속 나오게 해 관계의 비대칭을 표현.
- 격파는 23호의 기존 사망 모션과 명령선 단절로 마무리. 웰즈의 사망·도주 여부는 **미확인**이며 별도 연출을 전제하지 않음.

**4. 빼는 게 나은 것**

- **같은 송전기 두 번:** 두 번째는 구출 또는 이동 시험으로 교체해 “새 구간을 돌파했다”는 감각을 줌.
- **훅·점프·드론·바닥의 무제한 중첩:** 특히 구출 정면과 이동 목적지를 동시에 공격하지 않도록 예약.
- **솔로의 잡기 구출 의존:** 간파 가능한 돌진으로 교체하고 실패 피해는 유지.
- **초심자에게 보스 벽 밀기의 필수화:** 취약 중 넉백은 선택적 숙련 보상으로 두고 기본 공략에서 제외.
- **새 낙사·즉사·긴 조작 불능:** 4주에는 도입하지 않음. 어퍼 에어본·잡기 던지기도 각본 완성보다 후순위; 현재 훅은 비어 있습니다. [관련 구현](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:1630), [던지기](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:2341)

**5. 4주 안에 현실적인 우선순위**

1. **변형 격리·전시 재도전 흐름:** 새 프리팹·SO·변형 전용 각본 분기부터 구성. 부활 입력은 여전히 디버그 F10이므로 실제 규칙 연결이 선행 조건입니다. [PlayerReviveController.cs](Assets/1.Scripts/Player/Life/PlayerReviveController.cs:7)
2. **각본 예약·위험 정지·안내:** 1주차. HP 임계 이벤트와 종료 정리를 먼저 잡아 모든 기믹이 얹힐 기반을 확보.
3. **A안 송전탑 유도 파괴:** 2주차. “적의 공격을 역이용했다”는 가장 강한 새 재미를 우선 완성.
4. **구출의 솔로 변환·최종 공동 제압:** 3주차. 협동 장면과 클리어 직전 성취를 연결; B안 전체 제작은 선택 범위에서 제외.
5. **초심자·1~3인·클라이언트 QA:** 4주차를 확보. 기존 보스와 새 변형을 같은 조건으로 비교하고 설명 없이 이해되는지 관찰.

**6. 위험**

- **인원 밸런스:** HP는 1/1.7/2.4배를 시작 가설로 시험하되 직업별 실측 DPS로 조정. 탑 개수만 늘려서는 전투 길이가 맞지 않음.
- **인원 감소:** 각본 시작 인원을 기준으로 목표를 정하고, 연결 종료 시 남은 과제를 줄임. 구출 가능한 생존자가 없어지면 솔로 돌진 규칙으로 전환.
- **HP 구간 건너뛰기:** 현재는 최종 도달 페이즈와 예약 bool을 사용하므로, 여러 임계치를 넘는 피해에 대비한 순차 예약이 필요합니다. [EvaluatePhase](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:5623)
- **서버 권한:** 대상·고정 좌표·마스크·마감 시각·성패는 서버 확정. 클라이언트는 같은 정보를 표시하며, 드론 모델 충돌을 판정으로 사용하지 않음.
- **종료 처리:** 사망·전멸·디스폰·성공·타임아웃에서 구속·표식·탑·장판을 모두 해제. 기존 정리 경로를 각본도 따라야 합니다. [AbortAttackChain](Assets/1.Scripts/Monster/Boss/TwentyThreeBoss.cs:2364)
- **가독성:** 빨강=피해, 파랑=간파를 유지. 안전 안내는 흰 테두리·화살표·아이콘으로 구분하고 한 순간의 지시는 하나로 제한.
- **구현 비용:** 각본 핵심 함수에 비공개가 많아 상속만으로 끝나지 않음. 변형 전용 분기는 필요하지만, 4주 중 공통 FSM 전면 재작성은 피하는 편이 현실적입니다.
