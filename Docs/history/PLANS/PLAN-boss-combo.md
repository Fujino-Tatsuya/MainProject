## 2. 지금 코드 (조사)

- **각본 큐가 이미 있다**: 레이드 ① `raidOpeningScript` → `_raidScript` 큐 → `TryScripted`(쿨다운 무시 · 거리창 지킴 · 전역 간격 1.5초 지킴). 단 **레이드에서만** 채운다(`OnServerLogicResumed`).
- **우선순위**(`SelectAttackSlot`): 페이즈 시퀀스 → ③ 구출 각본 → ① 각본 → Dev 예약 → 전역 간격 → 룰렛.
- **연속 제한**: 직전 공격 가중치 ×`repeatPenalty`(0.3), `repeatBlockAfter`(2)회 연속이면 제외 — 룰렛에만 걸린다.
- **돌진 끝**: `TickDash` → `StopDash`(벽에 박았으면 끌고 간 사람 기절 + 바깥 넉백) → Recovery.
- **잡기 판정**: 끌어당김 시작에 반경 `coneRadius` + `InAttackCone`(예고와 같은 기준) 안의 사람만 끌고, 없으면 헛잡기.
- **어그로 교체 지점**: `ShouldReacquireTarget`(위협 교체 · 8초 주기) — Idle/Chase 에서만. 즉 **콤보 타 사이에도 돈다**. 점프·돌진의 `FarthestPlayer` 는 `AdoptAggro` 로 대상을 바꾼다.

## 3. 설계

### 3.1 데이터 (`BossDataSO`, 인스펙터 저작 — 배열이라 xlsx 대상 아님 `[DataTableIgnore]`)
```
[Serializable] class BossComboEntry {
    string name;                 // 로그·전투 기록용
    float weight;                // 룰렛 가중치(0 = 안 뽑힘)
    int allowedFromPhase;        // 단타 행과 같은 규칙
    float cooldown;              // 콤보 자체 재사용 대기(초)
    BossComboStep[] steps;
}
[Serializable] struct BossComboStep {
    BossAttackId attack;
    bool onlyIfGrabbable;        // C3 잡기: 앞 타가 끝난 순간 잡기 부채꼴에 유효 플레이어가 있어야 낸다(없으면 콤보 종료)
}
BossComboEntry[] combos;
BossAttackId[] openingCombo;     // C4 — 전투 시작 1회. 기존·레이드 공통(raidOpeningScript 대체)
float comboStepInterval = 0.3f;  // 콤보 안 타 사이 간격(xlsx 대상 — 행 없으면 SO 값)
float raidOpeningStepInterval = 1f; // 레이드 ① 개전만 — 배우는 구간(팀장 10-18: 1.5 → 1초)
```

### 3.2 선택 — 룰렛에 콤보를 섞는다
- 룰렛 후보 = 기존 단타 행 + **콤보**. 콤보는 아래를 다 만족할 때만 후보가 된다.
  - 가중치 > 0 · `allowedFromPhase` 통과 · 콤보 자체 쿨다운 끝
  - **첫 타**가 단타 게이트(거리창)를 통과. 첫 타의 행 쿨다운은 **본다**(같은 훅이 쿨인데 콤보로 우회하지 않게)
- 뽑히면 첫 타를 바로 내고, 나머지 타를 콤보 큐에 넣는다. 원거리 압박(§PLAN-boss-aggro 3.3)은 단타 행에만 적용한다.

### 3.3 실행 — 콤보 큐
- 우선순위: 페이즈 시퀀스 → ③ 구출 → **콤보 큐(개전 C4 포함)** → Dev 예약 → 전역 간격 → 룰렛.
- 타 사이 간격 = `comboStepInterval`(0.3초, 직전 공격 **종료** 기준 — 전역 간격과 같은 기준점). 쿨다운 무시.
- 다음 타의 거리창이 안 맞으면 **콤보 버림**(대기·추격 없음) → 다음 틱부터 평소 룰렛(전역 간격 1.5초부터).
- `onlyIfGrabbable` 타: 낼 순간 잡기 부채꼴(반경 `coneRadius` · `InAttackCone` · 공격 가능 플레이어)에 아무도 없으면 버림.
  - 돌진이 벽에 박혀 끌고 간 사람이 넉백으로 범위 밖에 나가면 잡기는 안 나간다(조건대로).
- 콤보 타는 기존 단타 경로(`StartAttack`)를 그대로 탄다 — 애니·예고·판정·간파 창·쿨 기록 모두 기존 그대로.

### 3.4 어그로 고정
- 콤보가 시작될 때의 어그로 대상을 고정한다. 콤보 동안
  - `ShouldReacquireTarget` 은 위협 교체·8초 주기 모두 **하지 않는다**.
  - `FarthestPlayer` 행(점프·돌진)도 콤보 안에서는 **고정 대상**을 노린다(승계 없음).
  - 예외: 돌진 캐리(끌고 간 사람이 어그로를 가져감)는 유지 — 캐리 대상이 곧 바로 앞 사람이라 C3 와 맞는다.
- 고정 대상이 죽거나 유령이 되면 콤보를 버린다.

### 3.5 ~~훅·훅 → 다음 돌진~~ — 삭제(팀장 10-18)
- 훅·훅·돌진은 콤보 C1 이 맡는다. 룰렛에서 우연히 훅이 연속으로 나와도 따로 처리하지 않는다.

### 3.6 끊기 — 콤보 큐·훅 예약을 비우는 곳
간파 성공 · 취약 넉백 · 제압 · 그로기 · 사망 · 페이즈 시퀀스 예약 · ③ 구출 예약 · ④ 자폭 · 전투 시작/재도전(`OnServerLogicResumed`) · `AbortAttackChain` · 고정 대상 사망/유령.

### 3.7 개전 C4 (기존·레이드 공통)
- `OnServerLogicResumed` 에서 기존·레이드 모두 `openingCombo` 를 콤보 큐에 넣는다(타 사이 0.3초, 사거리 이탈이면 버림).
- 타 사이 간격: 레이드 = `raidOpeningStepInterval`(1초), 기존 = `comboStepInterval`(0.3초). 레이드 ① 의 돌진 자막(`BOSS_RAID_OpeningDash`)은 레이드에서만 유지. `raidOpeningScript` 칸은 `openingCombo` 로 옮기고 지운다(값 이전).

## 5. 리스크
- **이미 0.3초로 붙는 공격**: 훅 클립의 회복(attackDuration)이 끝난 뒤 0.3초라, 실제 체감 간격은 회복 길이 + 0.3초다. 더 붙여야 하면 다음 타 시작을 회복 도중으로 당기는 건 별도 작업(애니 전이).
- **쿨다운 압박**: 콤보 타도 행 쿨을 기록한다 → 콤보 직후 룰렛에서 훅·어퍼가 한동안 안 나온다(근접에서 점프·돌진만 남을 수 있다). Play 로 보고 콤보 쿨·가중치로 조정.
- **연속 제한**: `repeatPenalty`/`repeatBlockAfter` 는 룰렛 단타에만 걸린다. 콤보로 같은 훅이 두 번 나오는 건 허용(의도).
- **레이드 각본과 우선순위**: ③ 구출·④ 자폭·② 차징이 콤보보다 먼저다 — 예약되는 순간 콤보를 버린다.
- **위협 어그로**: 콤보 동안 교체가 멈추므로 원거리 딜러가 1등이어도 콤보가 끝나야 넘어간다(최대 콤보 길이만큼 지연).
- **1인(`No23_Solo`)**: 넣지 않는다(팀장 10-18) — 코드는 같아도 콤보 데이터가 비어 있으면 예전 동작. 개전도 `openingCombo` 가 비면 없음.

## 6. 검증
- EditMode(`BossComboPolicy`): 후보 조건(가중치·페이즈·콤보 쿨·첫 타 거리·첫 타 쿨) · 다음 타 거리 이탈 = 버림 · `onlyIfGrabbable` 없음 = 버림 · 끊기 사유별 큐 비움.
- 기존 전투 176 · 보스 패턴 10 회귀.
- Play(기존·레이드, 1인·MPPM 2인)
  1. 개전 = 오른훅 → 왼훅 → 돌진(0.3초 간격, 사거리 밖으로 빠지면 거기서 끊김)
  2. 훅·훅 / 훅·어퍼 콤보가 룰렛에서 섞여 나오고, 콤보 동안 대상이 안 바뀐다
  3. 돌진 후 앞에 사람이 있으면 바로 잡기, 없으면(벽 넉백·회피) 잡기 없음
  4. 훅·훅·돌진 콤보가 룰렛에서 나온다(돌진은 고정 대상에게)
  5. 간파·취약·제압·차징 진입 시 남은 콤보가 나오지 않는다
- 전투 기록 로그에 콤보 발동·완주·버림 횟수 추가.

## 8. Codex 교차 검토 반영 (10-18)
- `AbortAttackChain` 은 정상 종료에도 불린다 → 콤보 취소는 명시적 중단 지점(간파·취약 넉백·제압·그로기/피격/넉백/복귀/사망 상태·페이즈 예약·전투 재개·디스폰)에서만.
- `TryScripted` 재사용 안 함 — 간격 대기와 거리 이탈을 구분하는 `BossComboPolicy.NextStep`(개전 첫 타만 이탈 = 대기).
- 큐 대신 "지금 콤보 + 다음 인덱스 + 고정 대상". 마지막 타의 공격이 끝나고 다음 선택 때 완주 처리 → 그때까지 고정 유지.
- 고정 = `ShouldReacquireTarget` 차단 + 고정 대상 유효성 독립 검사(어긋나면 버림) + 콤보 안 FarthestPlayer 는 고정 대상 + 승계(캐리·잡기 대상)는 고정도 옮김.
- 취약 넉백은 타 사이(Idle)에도 끊는다(`StartVulnerableKnockback` 진입).
- 룰렛: 단타·콤보 후보를 둘 다 센 뒤 판단. 접촉 사거리 갱신을 콤보 판정 앞으로.
- 돌진 → 잡기: 낼 순간 잡기 거리(행 개시 상한) 안의 붙잡을 수 있는 플레이어(생존·미구속·슈퍼아머 아님) 중 최근접으로 고정을 옮긴다.
- 개전 데이터 = 오른훅 → 왼훅 → 돌진, 1인은 빈 배열(코드 기본값).

## 9. Play 후 수정 (10-19 팀장)
- Play 로그: 훅 콤보 4번 중 3번이 2타째 "사거리 이탈"(1인 — 1타 뒤 물러남), 돌진·잡기는 "잡을 대상 없음"(판정 반경을 행 개시 상한 3.4m 로 잡은 버그 — 실제 끌어당김은 8m).
- **짧은 추격 유예** `comboChaseGrace` = 1초 — 다음 타가 사거리 밖이면 1초까지 다가가서 잇고, 못 붙으면 버린다.
- **돌진 → 잡기 = 무조건 시전**: `onlyIfGrabbable` → `forceFire`(사거리 무시 · 시작 순간 어그로 대상으로 즉시 회전 — 돌진 끝엔 벽을 보고 있어 위협이 없었다). 잡을 사람 찾기 판정은 삭제. 다른 콤보는 그대로.
- 버림 로그에 대상 거리·허용 거리·추격 시간을 찍는다.
- 전투 EditMode 192/0(콤보 16).
- 10-19 C5 점프·돌진 추가(가중치 15 · 콤보 쿨 8초 임시, 데이터만).
