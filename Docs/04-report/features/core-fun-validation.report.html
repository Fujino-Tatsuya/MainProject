1. 핵심 요약

Project MT는 2026년 5월 기존 익스트랙션 방향에서 노드 기반 탑다운 협동 액션 로그라이트로 변경되었다. 7월 개발의 핵심은 콘텐츠 수를 늘리는 것이 아니라 한 세션의 전체 흐름을 실제 플레이 가능한 수직 슬라이스로 연결하는 것이다.

현재 코드에는 근접 플레이어의 이동, 데이터 기반 4타 기본 공격, 상태 처리와 보스 주요 패턴이 들어가 있다. 그러나 스킬 3종, 인터럽트 결과 처리, Groggy 연동, 일부 네트워크 동기화와 보스 기믹 연결은 아직 완성되지 않았다.

현재 판정: 주요 전투 기능의 구현물은 존재하지만 전체 통합 및 플레이 검증이 필요한 단계.

2. 프로젝트 방향과 핵심 재미

장르노드 기반 탑다운 협동 액션 로그라이트
플레이 인원1~3인
네트워크Listen Server 기반
맵부분 절차 생성형 노드 맵
전투 중심패턴 인지와 대응 선택
7월 목표웰즈·23호 보스 전투 수직 슬라이스
  1. 몬스터의 공격 전조와 패턴을 확인한다.
  2. 기본 공격과 특수 공격을 구분한다.
  3. 공격, 회피, 인터럽트 중 적절한 대응을 선택한다.
  4. 인터럽트 성공으로 Groggy를 만든다.
  5. Groggy를 누적해 Break를 유도한다.
  6. 최대 3인이 취약 시간에 공격을 연계한다.

핵심 재미는 공격력으로 적을 압도하는 것이 아니라 패턴을 읽고 끊을 공격과 피할 공격을 판단하는 과정이다.

origin/feature/Player는 origin/feature/Wells&No.23를 병합해 플레이어와 보스 구현을 모두 포함한다.

구분내용

인터럽트 상태전진·애니메이션은 존재하지만 적 패턴 취소, 공격 판정 제거, Groggy Count, Groggy/Break 전환은 미확인

5. 웰즈·23호 보스

23호는 근접 전투 본체, 웰즈는 상부 탑승자로 폭탄과 보조 공격을 담당한다. AI, 이동, 피해, 패턴과 장판은 Server 권한이며 Unity Behavior Graph와 Blackboard를 사용한다.

패턴기획 내용코드 상태
Hook좌·우 독립 단타상태·선택 구조 존재
Upper어퍼컷과 공중 상태상태 존재
Grab잡기→지속 피해→던지기컨트롤러 존재
Jump대상 위치 점프와 착지 AoE서버 판정·예고 RPC 존재
Dash대상 방향 돌진과 경로 타격상태·컨트롤러 존재

폭탄

투척, 기본 공격 반사, 포물선 이동, 충돌 폭발, 화염 장판과 중첩 확대가 기획되어 있다. 관련 코드가 존재하지만 플레이어 평타와 폭탄 반사의 통합 판정은 실제 검증이 필요하다.

송전기·차징

인원수에 따라 송전기 수가 달라지고 제한시간 내 해제 성공 시 Groggy, 실패 시 Rage로 전환된다. 관련 컨트롤러는 있으나 Boss Room에서 송전기 목록을 전달하는 코드가 주석 처리되어 있다.

3페이즈

1페이즈HP 100~66%
2페이즈HP 66~33%
3페이즈HP 33% 이하

상태와 Behavior Graph 에셋은 존재하지만 실제 HP 임계값 전환은 Unity 실행 검증이 필요하다.

6. 일반 몬스터

근접 몬스터: Enemy, EnemyBTActivator, TrashMobState, CommonMeleeRobot와 Server 전용 AI·NavMesh 구조가 있어 1차 구현 상태로 판단한다. 통합 검증은 남아 있다.

원거리 몬스터: 현재 브랜치에서 구현을 확인하지 못했다. 7월 제출 범위에서 제외하고 이후 중간 보스 작업과 함께 재조정한다.

10. 면담 피드백 및 지시사항

  • 콘텐츠 확장보다 한 세션이 끝까지 작동하는 수직 슬라이스를 우선한다.
  • Stage 구역 10개와 Boss Room 1개를 연결한다.
  • 근접 캐릭터의 기본 공격, 인터럽트, 스킬 3종을 완성한다.
  • 인터럽트, Groggy, Break와 협동 연계를 핵심 재미로 검증한다.
  • 일반 근접 몬스터와 보스 전투를 우선하고 원거리 콘텐츠는 후순위로 조정한다.
  • 송전기, 폭탄, 잡기, 차징, 보스 페이즈를 실제 플레이로 검증한다.
  • Result와 보상 표시 후 Lobby 복귀 흐름을 완성한다.
  • Host와 Client에서 동일한 전투 결과를 MPPM으로 확인한다.
  • 7월 24일 내부 버전, 7월 27일 제출 버전을 목표로 한다.
  • 기존 보스 구현과 새 통합 구현의 차이를 보고한다.

교수님 보고용 최종 요약

본 프로젝트는 최대 3인이 참여하는 노드 기반 탑다운 협동 액션 로그라이트입니다. 7월 목표는 Stage 구역 10개와 별도 Boss Room을 연결하고, 근접 플레이어가 일반 몬스터 및 웰즈·23호 보스와 전투한 뒤 결과 화면을 거쳐 대기실로 복귀하는 수직 슬라이스를 완성하는 것입니다. 현재 근접 플레이어의 이동, 4타 기본 공격, 상태 처리와 보스의 Hook, Grab, Jump, Dash, Bomb, Charging 패턴은 코드에 구현되어 있습니다. 다만 스킬 3종, 인터럽트와 Groggy 연동, 송전기 연결, 잡기 네트워크 동기화 및 전체 플레이 검증은 남아 있습니다. 따라서 7월 24일까지 새로운 기능 확장보다 기존 전투 기능과 네트워크 플레이 루프의 통합 및 안정화에 집중하고, 7월 27일 제출 가능한 빌드를 완성하는 것을 목표로 합니다.
