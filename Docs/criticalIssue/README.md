# criticalIssue — 치명 이슈 기록

게임 진행을 막거나, 특정 환경에서만 조용히 터져 재현·원인 파악이 어려웠던 이슈를 남긴다.
같은 함정을 다시 밟지 않는 것이 목적이다 — 증상만이 아니라 **왜 그 환경에서만 났는지**와 **어떻게 확정했는지**를 적는다.

## 작성 규칙

- 파일 이름: `YYYY-MM-DD-<짧은-kebab-요약>.md` (발견일 기준).
- 상단 표에 **상태**(조사 중 / 원인 확정 / 수정됨 / 재발 방지 완료)와 담당을 둔다. 상태가 바뀌면 갱신한다.
- 확인된 사실과 추정을 구분한다. 근거는 파일:줄, 로그 줄, 커밋으로 단다.
- 수정이 끝나면 수정 커밋과 검증 방법을 적고, 재발 방지 장치가 무엇인지 남긴다.
