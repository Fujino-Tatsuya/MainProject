# Toon Shader 아트 인수인계 가이드

> 블루아카이브풍 SD 캐릭터 셀셰이더 (URP17 / Unity 6). 레퍼런스 룩은 **젠레스 존 제로(ZZZ)**.
> 프로그래머가 기본 셋업 후 아트가 인스펙터에서 미세 튜닝하는 워크플로.
>
> **⚠️ 판단 기준은 실제 Play 탑다운 화면이다.** 프리팹 프리뷰·부트스트랩 씬은 카메라 거리와
> 라이팅이 달라 아웃라인 두께와 음영 대비가 전혀 다르게 보인다. 프리뷰만 보고 값을 정하지 말 것.

## 0-A. 🔴 시도했다가 되돌린 것 — AO 크리즈 음영 (2026-07-31)

**다시 시도하기 전에 반드시 읽을 것.**

레퍼런스(블루아카이브 콜라보 일러) 분석 자체는 유효하다: 전체는 밝고, 어두운 곳은 **가려진 곳**
(턱밑·앞머리 아래·겨드랑이·팔↔몸통 겹침·치마 안쪽·관절)뿐이다. 그건 램버트가 아니라 AO 다.
그래서 URP SSAO 값을 읽어 툰답게 계단화하는 "크리즈 음영"을 넣었다 — **결과는 실패했다.**

- 증상: 캐릭터 표면 전체에 **얼룩 반점**이 잔뜩 생기고, Paladin 얼굴이 어두워졌다.
- 원인: `PC_Renderer` 의 SSAO 가 **Samples=1 / BlurQuality=0** 으로 노이즈가 매우 심하다.
  그 값을 `smoothstep` 으로 계단화하면 노이즈가 그대로 **하드한 반점으로 증폭**된다.
  (부드럽게 곱하면 노이즈가 눌리지만, 계단화는 노이즈를 강조하는 연산이다.)
- 재시도 조건: **먼저 SSAO 품질을 올려라**(Samples↑ / BlurQuality↑ / Downsample 검토).
  그게 안 되면 계단화 대신 완만한 곱셈, 또는 화면공간 AO 대신 **버텍스 컬러 / 텍스처 AO**를 쓴다.
- 같이 되돌린 것: 얼굴 `_FaceSoften`(플랫 교체 → 완화) 개편, 하이키 값 세트(Shade Tint 밝게 /
  Ambient Fill 0.55 등). 현재 셰이더·머티리얼은 **팀장 승인 룩**으로 복구돼 있다.

> 남아 있는 알려진 이슈(추후 비주얼 작업에서 다룬다):
> - Paladin 얼굴 하단(입·코)에 회색 덩어리 — `_FaceFlatten` 교체 경계가 얼굴을 가로지른다.
>   `_FaceLiftHeight` 를 턱 아래(목)로 내리면 완화되지만, 이번엔 룩 고정을 위해 손대지 않았다.
> - Paladin 머리카락이 얼굴과 같은 높이대라 함께 플랫 처리돼 음영이 없다(단일 서브메시 한계).

## 0-B. 경계의 모양 — ZZZ 4단계 중 마지막

ZZZ 강의의 셀음영 4단계: `Half Lambert gradient` → `round(x)` → `step(0.2,x)` → **`smoothstep(0.2,0.25,x)`**.

목표는 마지막 것 — **경계는 또렷하되 계단(밴딩)이 없는 상태**다. 그래서:

- `Shade Smoothness`는 **좁게** 둔다(0.02~0.04). 넓히면 그라데이션이 되어 셀룩이 사라진다.
- 대비는 경계 폭이 아니라 **`Shade Tint`(그림자 색)** 와 **`2nd Shade Level`(중간밴드 밝기)** 로 만든다.

## 3. ToonLit 프로퍼티 — 뭘 조절하면 뭐가 바뀌나

### ★ Character Key Light (맵 조명 독립) — 가장 중요

캐릭터가 어두운 맵에서 같이 죽는 문제의 **뿌리**였다. 예전에는 `Fixed Light` 토글이 음영
**방향만** 고정하고, 최종 색에는 씬 메인라이트 색이 그대로 곱해져 있었다.

| 프로퍼티 | 효과 |
|---|---|
| **Char Light Blend** | `0` = 예전 동작(씬 라이트 종속) / **`1` = 완전 독립**(아래 키라이트만 사용). 기본 1 |
| **Char Key Color** | 캐릭터 전용 키라이트 색. 맵과 무관하게 캐릭터 톤을 결정 |
| **Char Key Intensity** | 키라이트 강도. **캐릭터가 어둡다 = 여기를 먼저 올린다** |
| **Char Ambient** | 키라이트 기준 환경광. 그림자부 바닥 밝기(맵 SH 대체) |

> 맵 라이팅을 아무리 만져도 캐릭터 밝기가 안 변하는 게 **정상 동작**이다.
> 반대로 맵 분위기에 캐릭터를 섞고 싶으면 Blend 를 0.3~0.6 으로 낮춘다.
> 포인트/스폿(횃불 등) 추가광은 Blend 와 무관하게 계속 캐릭터에 얹힌다 — 의도된 동작.

### Cel Shading (셀 음영)
| 프로퍼티 | 효과 |
|---|---|
| **Fixed Light** (토글) | 켜면 씬 라이트 방향을 무시하고 아래 고정 방향으로 음영 |
| **Fixed Light Dir** | ⚠️ **월드공간**이다. 캐릭터가 회전해도 음영 방향이 화면 기준으로 고정된다. 현재 `(0.5, 0.55, 0.4)` = 사광(우상단 전방) |
| **Shade Tint** | 그림자부 색. **어둡게 = 대비↑.** 음영을 진하게 하는 1순위 노브 |
| **Shade Threshold** | 밝은면↔그림자 경계 위치(half-lambert). 0.5 = 기하학적 명암경계 |
| **Shade Smoothness** | 경계 부드러움. **0.02~0.04 유지.** 넓히면 셀룩이 죽는다 |
| **2nd Shade Threshold / Smoothness** | 더 어두운 2단 그림자의 위치/폭 |
| **2nd Shade Level** | 중간 밴드의 밝기. **낮추면 2단이 깊어져 대비↑** (0.5 = 예전 동작) |
| **Shade Strength** | 음영 전체 세기 |
| **Ambient Fill** | 그림자부 밝기. **높이면 그림자가 밝아짐**(대비↓) |

> ⚠️ **수직광 함정.** `Fixed Light Dir` 을 `(0.15, 1, 0.35)` 처럼 거의 수직으로 두면
> 탑다운 카메라에서 보이는 면이 전부 고르게 밝아 **음영이 생길 자리가 없다.**
> 값(Shade Tint 등)만 진하게 해도 화면에 안 나타난다 — 먼저 **광원을 눕혀야** 한다.

### Face Lift (단일 서브메시 모델의 얼굴 분리)
| 프로퍼티 | 효과 |
|---|---|
| **Face Lift** (토글) | 켜면 아래 높이 이상 영역을 "얼굴"로 취급 |
| **Face Lift Height** | 피벗(발밑) 위 몇 m 부터를 얼굴로 볼지. Paladin `1.42` (루트 캡슐 실측 height 1.79 / center.y 0.88 → 얼굴 약 1.45~1.75m) |
| **Face Lift Smooth** | 경계 부드러움 |
| **Face Lift Ambient** | 얼굴 영역 Ambient Fill |
| **Face Flatten** | 얼굴을 셀음영·라이트연산에서 떼어내는 비율. **1 = 완전 플랫** |
| **Face Brightness** | 플랫로 보낸 얼굴의 밝기 배수. **몸을 진하게 갈수록 여기를 올린다** |

> ⚠️ **이 방식의 알려진 한계 두 가지** (§0-A 참고, 개선 시도는 롤백됨):
> 1. **머리카락이 얼굴과 같은 높이대**라서 함께 플랫 처리된다 → Paladin 머리 음영이 없다.
>    부위별 서브메시가 확보되면 해결된다.
> 2. 교체 경계가 톤 점프로 보인다. `Face Lift Height` 가 턱 높이면 전이 구간이 얼굴 정면을
>    가로질러 **입·코 위에 회색 덩어리**가 생긴다. 경계는 **턱보다 아래(목)** 가 안전하다.

> 오브젝트공간 Y 가 아니라 **피벗 위 높이**를 쓴다. 블렌더 Z-up 모델은 X −90° 로 눕혀
> 임포트되므로 오브젝트 Y 가 위쪽이 아니다(마스크가 위/아래가 아니라 앞/뒤로 잘린다).
>
> 정석은 SDF 얼굴 그림자다. fbx 에 얼굴 서브메시 + SDF 그림자맵이 준비되면 이 토글을 끄고
> Skin 머티리얼로 옮긴다. **현재는 아트 미보유 → 높이 마스크로 대체(승인됨).**

### Rim Light (역광 테두리)
| Rim Color / Power / Intensity / Align | 외곽 프레넬 역광. Align은 광원쪽만 비출 비율 |

> 림은 **얼굴 플랫 처리보다 뒤에** 계산된다 — 얼굴도 테두리를 유지해 머리 실루엣이
> 배경에 묻지 않게 하려는 의도다. 순서를 바꾸지 말 것.

### Hair Anisotropic (머리 전용, Hair Mode 토글)
| 프로퍼티 | 효과 |
|---|---|
| **Hair Mode** (토글) | 켜면 엔젤링(천사링) 하이라이트 |
| **Hair Spec Color** | 하이라이트 색. **어둡게 = 은은**, 밝게 = 강렬 |
| **Hair Spec Threshold** | 밴드 위치. **높이면 밴드가 얇아짐** |
| **Hair Spec Smoothness** | 밴드 부드러움. **낮을수록 얇고 또렷** |
| **Hair Highlight Shift** | 밴드를 위/아래로 이동 |
> ⚠️ 이방성은 메시 **탄젠트 방향**에 의존. fbx 탄젠트가 머리카락 흐름과 어긋나면 밴드가 넓거나 엉뚱하게 뜬다.

### Metal Toggle (메카 23호 등, Metal Mode 토글)
| Metal Mode / Spec Color / Threshold / Smoothness | 금속용 하드 스페큘러 |

> 🔴 **No.23 은 Metal OFF 로 유지한다.** 켰을 때 흰 스페큘러 반점이 표면에 흩뿌려져
> 때깔이 망가졌고, 컨셉아트에도 스페큘러가 없다. 검·방패도 같은 이유로 OFF.

### Tone (톤)
| Brightness | 전체 밝기 |
| Saturation | 채도 |

### Outline (외곽선)
| 프로퍼티 | 효과 |
|---|---|
| **Outline Screen Space** (토글) | ★ 켜면 **화면 기준 px 두께 고정**(거리 보정). 켜는 게 기본 |
| **Outline Pixels** | 화면상 두께(px). 탑다운 권장 **2.5~4** |
| **Outline Width** | 오브젝트공간 두께 — 위 토글이 꺼졌을 때만 쓰는 **폴백** |
| **Outline Darken** | 표면색 대비 어둡기. **낮출수록 진한 선** (0.25 권장) |
| **Outline Min Luminance** | 검은 파트(머리/옷/스타킹) 최소 밝기 보정 |
| **Outline Tint** | 표면색에 곱하는 전역 틴트 |

> 아웃라인 색은 **표면색에서 색조를 따온다** — 부위별로 손으로 색을 지정할 필요가 없다.
> 검은 파트는 albedo≈0 이라 단순 곱으로는 선이 사라지므로 Min Luminance 가 하한을 준다.
>
> ⚠️ **왜 화면공간이 필요했나:** 오브젝트공간 고정 두께는 카메라가 멀어지면 화면상 두께도
> 같이 줄어든다. 탑다운(카메라 십수 m 위)에서 `0.006~0.008` 은 **1px 미만**이 되어
> "아웃라인이 안 보인다"가 됐다. 값을 키우면 근접 컷신에서 캐릭터가 뭉갠다 — 그래서 보정식이 답.
>
> ⚠️ **하드에지 메시 한계:** 인버티드 헐 방식은 노멀이 분리된 저폴리 메시(검·방패 등)의
> 모서리에서 선이 끊긴다. fbx 에서 스무딩/노멀 병합이 필요하면 아트 작업으로 넘긴다.

## 5. 아트 작업 가이드 — 증상별 처방

| 증상 | 먼저 만질 것 |
|---|---|
| 캐릭터가 전체적으로 어둡다 | **Char Key Intensity** ↑ (맵 라이트를 만져도 안 변하는 게 정상) |
| 음영이 안 읽힌다 / 평평하다 | **Fixed Light Dir 을 눕힌다**(사광) → 그 다음 Shade Tint ↓ / 2nd Shade Level ↓ |
| 주름·관절 음영이 없다 | 현재 방법 없음 — §0-A(AO 롤백) 참고. 텍스처/노멀맵 아트 작업이 필요하다 |
| 음영 경계가 그라데이션이다 | **Shade Smoothness** ↓ (0.025 전후) |
| 아웃라인이 얇다 | **Outline Pixels** ↑ (Outline Width 가 아니다 — 토글이 켜져 있으면 무시된다) |
| 아웃라인이 옅다 | **Outline Darken** ↓ |
| 얼굴이 어둡다/음영이 지저분하다 | **Face Brightness** ↑, **Face Flatten** 1.0, **Face Lift Ambient** ↑ |
| 얼굴 밝은 영역이 목/가슴까지 내려온다 | **Face Lift Height** ↑ |
| 엔젤링 다듬기 | `Hair Spec Threshold`↑ + `Hair Spec Smoothness`↓ → 얇은 링 |

## 7. 남은 작업 (아트 의존)

- **얼굴 SDF 그림자** — Wells 는 `welz_face` 슬롯이 이미 분리돼 있으니 SDF 그림자맵만 오면
  가장 먼저 정석 적용이 가능한 캐릭터다. Paladin 은 서브메시 분리가 선행 조건.
- **Wells 엔젤링(Hair Mode)** — `Wells_Hair_Toon` 에서 켤 수 있게 준비돼 있으나 **현재 OFF**.
  이방성 밴드는 fbx 탄젠트에 의존해서 방향이 어긋나면 밴드가 엉뚱하게 뜬다 → 탄젠트 확인 후 켠다.
- **검·방패 텍스처** — 현재 단색.
- **하드에지 아웃라인 끊김** — 무기류 fbx 노멀 스무딩.
- **부위별 서브메시(Paladin)** — 확보되면 Skin/Hair/Cloth 머티리얼 분리가 정석.
- **Wells 보호창 툰화** — `Project/ToonGlass` 기반 반투명 툰 머티리얼이 필요하면 별도 작업.
- **주름·관절 음영(AO)** — §0-A 참고. 재시도 전 `PC_Renderer` SSAO 품질(Samples/Blur) 상향이 선행.
- **미사용 머티리얼 정리** — `Assets/3.Materials/Toon/` 에 이전 세션의 `Welz_Skin/Hair/Cloth/Glass/Toon.mat`
  이 남아 있으나 아무도 참조하지 않는다(Wells 는 `Wells_*_Toon` 을 쓴다). 확인 후 삭제 대상.
